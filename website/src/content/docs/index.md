SDD (Signal, Dialogue, Decision) keeps a project's thinking in a graph of signals and decisions, grown through dialogue between you and your agents.

- [What is SDD?](/sdd/what-is-sdd/): the problem it solves, how it works and what it gives you.
- [Getting started](/sdd/getting-started/): install sdd, set up a project and hold your first dialogue.
- [Entry kinds](/sdd/reference/entry-kinds/): what each kind of entry is for, when to choose it and how it ends.
- [Vision](/sdd/vision/landscape/): where SDD stands and where it is heading.

The source and the README are in the [SDD repository](https://github.com/networkteam/sdd).

SDD v0.18.0-alpha.2 is published at https://github.com/networkteam/sdd/releases/tag/v0.18.0-alpha.2, tagged on commit `b3dca4b0` as the second prerelease of v0.18.0.

Since v0.18.0-alpha.1 (20260912-140620-s-prc-1wa) it ships four deliveries: stateless HTTP serving (20260913-173213-s-tac-tz0), failed and cancelled operations served as positions (20260922-235352-s-tac-a05), summary and WIP writes published under the recorded intent with `sdd recover` removed (20260923-160657-s-tac-tii), and implementation runs without branch state or a landing step, with an unbound session's base derived from the serving checkout (20260924-091433-s-tac-9bu). The notes add two breaks, the `sdd recover` removal and the new `PublicationStore` interface that replaces the graph store's write methods for an external composition, and repeat alpha.1's breaks. It stays an alpha because the span breaks the application Go API again.

In the doing: local `main` was five commits ahead of `origin/main` at ship time, and `gh release create --target main` tags the remote branch, so the user pushed before the tag was created; the release skill has no step that checks this. A write left pending for retry by an alpha.1 session is not carried over, since its record went with the prepared-write path (20260923-160657-s-tac-tii); the agent captures such an entry anew, and the notes leave this out as an acceptable cost.

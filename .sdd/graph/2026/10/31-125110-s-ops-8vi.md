PR #25, merged into `main` as d8c4002a, replaces `hooks.post.install` with `hooks.post.install_steps` in `.goreleaser.yaml`. GoReleaser now renders the cask's quarantine-removal hook as a `postflight_steps` block that runs `/usr/bin/xattr -dr com.apple.quarantine {{staged_path}}/sdd` under `on_macos`. The published cask in `networkteam/homebrew-tap` changes with the next release, which rewrites it.

The review checked the change against GoReleaser's source, which renders `{{ .StagedPath }}` as Homebrew's `{{staged_path}}` token, and against Homebrew's Cask Cookbook, which allows `run`, `on_macos` and that token in `postflight_steps` and lets the step sandbox write to the caskroom. No GoReleaser v2.19 render ran in the review. The contributor's snapshot test reports the rendered `postflight_steps` block and a binary without the quarantine flag after install. The release workflow's `~> v2` resolves to v2.19.0, the first release with `install_steps`; a local `goreleaser check` needs v2.19 or later as well.

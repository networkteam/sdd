The public LLM surface is completed in two parallel packages: `pkg/llm` gains the chat composition pieces the local binary already uses, and a new `pkg/llm/embed` gives embedding the same shape chat got in the boundary rebuild. Provider adapters and the configuration-driven factories stay internal, and the local binary composes from the exported pieces, so an external host and the local binary run one code path. The [listing](./02-114838-d-tac-cov/llm-composition-surface.md) carries the signatures and composition examples.

Chat. The timeout decorator, the rate limiter, and the observing decorator with its call record and sink interface move from `internal/llm` to `pkg/llm` unchanged in shape, and a router that dispatches each call to a runner chosen by its purpose is added. The observing decorator wraps a runner and hands one call record per call to whatever implements the one-method sink; locally that is the JSONL file writer, a host implements it against its own store.

Embedding. Today its stats are recorded inside the provider adapters through a sink carried on the context, its public port returns vectors only so nothing outside the adapter can observe a call, and that port lives in `pkg/application` rather than beside the LLM contract. It converges on the chat shape: `pkg/llm/embed` defines a request carrying purpose and texts, a result carrying vectors, identity, and usage, an embedder interface with an embed method and a fingerprint, and the same three decorators, recording through the shared call record and sink. The context-carried sink and the adapters' self-recording are deleted, and the application's own embedding port is removed: the runtime options take an embedder the way they take the chat runner, and the application maps chunk IDs to positions and reads the vector space from the fingerprint itself. No compatibility layer; nothing consumes the public exports yet, so this is the moment to shape them.

Why the line runs at gollm and the provider adapters. gollm is unmaintained and behind the model providers, so code coupled to it is not worth publishing; the embedding adapters and both factories read private configuration. Everything exported is pure functions and types over vocabulary already public. Retry stays inside the gollm adapter because it reads provider headers a decorator over the one-method runner cannot see.

Why now: the first external consumer, a hosted composition on v0.17.0-beta.1, rewrote bounding, recording, and per-purpose routing over the public types, since `pkg/llm` exported the contract alone and per-purpose routing was never built (20260901-093840-s-tac-ahc). This refines the boundary directive (20260830-234501-d-cpt-q6n): contract, host duty, and private configuration stand; the observing decorator becomes reusable instead of host-owned, the call record becomes public API, and the embedding parity that directive left unchanged is now closed. Per-purpose model configuration for the local binary is a separate decision.

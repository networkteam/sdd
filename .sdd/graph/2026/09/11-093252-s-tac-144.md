Implemented deliberate index version collection in commits fba0390b and 76a99383 on branch worktree-index-gc, fulfilling 20260910-183941-d-tac-c9c and removing the cross-rule eviction reported in 20260910-182907-s-tac-ecp.

`sdd index` and the MCP reconcile only add versions; the collector that ran inside `sdd index` and the retention window that paced it are removed. `--force` replaces an entry's versions under the binary's own derivation rule and leaves other rules' rows in place. Every written version records its derivation rule beside the fingerprint as an additive manifest field; versions without the field classify by chunk-ID shape, and zero-chunk versions count as current-rule. `sdd index gc` reports each store's groups (`v1-current`, `v1-branch`, `v0`, `legacy`) with version and entry counts, age range and size, sums sizes from chromem's per-document files, and deletes only through `--drop <group>` or `--drop stale`, refusing the current group and unknown names before touching anything. `--repo` and `--all-repos` cover connected stores as on `sdd index`. The report renders like `sdd stats`: the styled ruled table on a terminal, JSON on a pipe or with `--format json`, through a ruled-table helper both reports now share. The `sdd index` result line now shows the store size. The report is a finder query, the drop a handler command under the exclusive write lock.

Run against this repository's real store, the report showed the two version groups the gap described: the current rule's versions and the previous release's `v0` group, the latter still growing while the v0.17.0 server ran.

Tests cover grouping and selection, force keeping other rules' rows, drop refusing the current group, the no-op stale drop, the MCP path recording the derivation, the report finder, and both report renderers. README and the search and CLI reference skill templates describe the command; commit b4063f32 refreshed the installed renders. Merge into main and the release remain pending; the running MCP server on this machine still needs the restart the directive names.

`SessionMetadata` loses its `CodecVersion` field: the port's typed metadata is the in-memory representation whose evolution is the Go type's own, serialization versioning belongs to each adapter's persisted format, and `StoredEvent.CodecVersion` stays engine-owned because only the engine can interpret the payload bytes it versions. Three different versions were conflated under one field name — the representation's evolution (the Go type itself), the adapter's persisted-format version, and the engine's payload codec; only the last is the port's to carry, and it already lives on `StoredEvent`.

The field never came from the design. The port was published without it, matching the recorded split of typed store-visible metadata against ordered, versioned opaque events (20260712-104530-d-tac-1mb — which versions events only); it arrived a day later in the fail-closed sweep implementing the seam review (20260712-194427-d-tac-wjq), whose retain-list names event, procedure, registry, finalizer, and envelope versions — a metadata version is not among them, and the review never re-asked which half needs one. In practice the field does no work: the version field and the shape-evolution logic sit on opposite sides of the port — metadata has already evolved (the holder fields deleted, `Ended` added, legacy endings recovered at read) through lenient decoding and read-side derivation while the codec constant stayed at 1. A schema-owning store versions metadata through migrations; only a blob-serializing adapter needs a shape discriminator, and the filesystem adapter already discriminates per line, so it owns whatever format versioning its record needs — under the permanent read-compatibility contract (20260602-203349-d-cpt-i2x), every line already written, including the codec value those blobs carry, stays readable.

With the field goes the metadata fail-closed check, which was the tripwire against a mixed-version deployment misreading sessions. The replacement stance is a documented constraint, not a guard: compositions must not run mixed engine versions against one session store; a session a newer engine actually advanced still fails closed through `StoredEvent.CodecVersion`. Raised by code-grounding of the public surface at v0.17.0-alpha.4 by an external consumer building against it.

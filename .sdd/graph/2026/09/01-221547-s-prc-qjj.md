SDD v0.17.0-beta.1 is published as the first beta of v0.17.0, at tag `e015052b`. It publishes the exported-surface cleanup with the session-port codec removal (20260901-192933-s-tac-ctm) and the pre-flight config fix (20260901-185333-s-tac-ckx), plus two smaller changes: summaries are now written in the graph's configured authoring language rather than the entry's, and a gollm bump carries provider fixes for reasoning-model temperature, OpenAI cache-read usage, and Anthropic effort. The GitHub release carries the notes, four platform archives, checksums, build provenance and `install.sh` as its published assets, and the prerelease safeguards held: the release carries the prerelease flag, `releases/latest` and the Homebrew cask both still resolve to v0.16.2.

**Why a beta rather than a fifth alpha.** Claude recommended alpha.5 and Christopher chose beta.1. The case for another alpha was that the reason alpha.4 was not v0.17.0 (20260831-201613-s-prc-spc) has not fully expired: the exported Go surface moved again in this very span, and one further break is already committed but unshipped, the `ProcedureRegistry` unexport bound to the CLI-onto-application migration (20260901-192114-d-tac-wuy). Christopher's call weighed feature-completeness, unchanged since alpha.4, over surface churn, which the exported-surface boundary test shipping in this same release (20260901-192933-s-tac-ctm) now guards by failing on any exported `pkg/` signature that names an internal type. The notes name the pending unexport under Breaking with a do-not-build-against-it line, so the beta claim stays honest about what is still to move.

**Evidence.** The release is at https://github.com/networkteam/sdd/releases/tag/v0.17.0-beta.1.

Embedding batch size becomes a composition concern: `pkg/llm/embed` gains a `Batched(e, size)` decorator that splits one request into calls of at most `size` texts and concatenates the vectors in input order, the OpenAI and Ollama adapters send exactly one HTTP request per `Embed`, and the local binary composes `Batched(Observed(RateLimited(Bounded(adapter, timeout)), sink), size)`, so deadline, rate, and recording apply per round-trip and embedding composes the way chat does.

The surface work (20260902-125432-s-tac-sv0) left two marks that this removes. The adapters kept their own splitting loop, so one application `Embed` covering a cold reconcile spans dozens of round-trips, and a whole-call `embed.Bounded` would have failed exactly those calls; the deadline therefore stayed in the adapters' HTTP client and the exported `embed.Bounded` went unused locally. And the CLI indexer carried the batch size beside the embedder in a struct, because the two-method contract has no `BatchSize`, the method the search work had put on the internal interface so the indexer could bucket without a magic constant (20260505-181352-s-tac-96a).

With `Batched` in the chain, size is a composition value like rps and timeout, owned by the site that reads the configuration. The adapters become transports with no policy. `Bounded` and `RateLimited` sit inside `Batched`, so each round-trip gets its own deadline and its own limiter wait; today the limiter waits once per `Embed` however many requests follow, which undercounts against provider limits. `Observed` sits inside `Batched` too, so the local stats keep one row per round-trip with `Items` equal to the request size, the grain they had before the surface work rather than one row per reconcile. A host that wants one row per call places `Observed` outside `Batched`; the grain is the site's choice, not the framework's.

The local factory returns `RateLimited(Bounded(adapter, timeout))` and exports the resolved size; the CLI applies `Batched` around its observed embedder and hands the same size to the indexer for its progress buckets, so a bucket is at most one request. Fulfilled when the adapters have no splitting loop, `embed.Bounded` is composed locally, and a full test run plus a live search pass. It extends the completed surface directive (20260902-114838-d-tac-cov) by one decorator and changes no public type it introduced.

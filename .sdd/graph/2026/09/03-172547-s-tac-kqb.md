Commits `9f69f410`, `60969936`, `25028183`, and `4bfa02f9` on branch `worktree-session-model` deliver the session model of 20260903-152247-d-cpt-yjc as refined by 20260903-172024-d-cpt-5tb, and the MCP handle is the bare session ID again, which resolves 20260903-113356-s-tac-ajf. The branch awaits Christopher's merge into `main`.

Store ownership: `ProjectRuntimeOptions` lost `Sessions`, `StagedBlobs`, and `Now`; `NewApplication` takes `ApplicationOptions{Access, Sessions, StagedBlobs, Clock}`, with `Clock` a named interface defaulting to the system clock. `AccessResolver` gained `AuthorizeSession(ctx, SessionAccessRequest{Actor, Owner, Session, Project})`; the shipped `OwnerOnly` is what the local composition, the test harness, and the example use, and every external composition must now implement the method. One door resolves every session-addressed operation: load by ID, `AuthorizeSession`, membership in the home project with the access the operation needs, codec validation. `LoadWorkflow`, `ResumeWorkflow`, `AbandonWorkflowSession`, `ReconcileMutation`, and `RecoverMutation` dropped their project parameter; the recovery pair keeps reading a concluded log, while the workflow doors refuse an ended session, and abandoning an already ended session is now refused where it used to overwrite the ending. The MCP server deleted its handle composition and `Options.Project`, returns the bare ID as `session` in every result, and `sdd sessions` lists and abandons by that ID.

Collection: `SessionFilter` gained `EndedBefore`, `After`, and `Limit`, `List` returns a page with the cursor to continue from, and `StagedSessions(ctx, after, limit)` pages in `SessionRef` order. `CollectSessions(ctx, cmd)` takes no identity or project, processes one page of each store, and returns `Next`; `sdd serve` loops pages at startup. The legacy-ending derivation selects on the derived ending while keeping the store's cursor, so a page thinned by that selection still advances. The session and staged-blob conformance suites exercise the paging, and the example's memory stores pass them.

Instance targets: an instance's project is recorded as a typed ledger event keyed by instance when the start call names one, written in the same append as the engine's start event, and derived from the dispatching parent or the home otherwise. `effectiveTarget` carries the instance's project beside the branch precedence; the session branch binding applies only at home. Reads, writes, the participant name, and the procedure list of an instance resolve through the target's runtime after two checks, the home's declared dependency closure walked through the configurations the composition can reach and membership in the target, asked again with write access at the write gate. `start_procedure` and the read tools take an optional `project`, and every serve names the project its instance works in. The local composition answers `ResolveProject` for a declared dependency with a runtime built from its cache, carrying the dependency's own declared dependencies and language and no write authority; its project listing still names the home alone, so a local session opens without choosing.

Deviations from the directive's text, each named here rather than silently dropped. The anchor is not a source of the project, settled in 20260903-172024-d-cpt-5tb after the engine refused the cross-repo form. The directive expects a write into a dependency to fail when the write acquires its target checkout. Locally it fails one step earlier, when the target's default branch resolves, because a local dependency runtime configures no default branch; that error names the project, and the checkout-acquisition error, for the day a dependency has one, now names project and branch too. The design record's `Next SessionRef` for the staged-blob page is merged into the pass's single `Next SessionID` as the earlier of the two stopping points, which re-enumerates a few staging areas per pass and stays idempotent. The tool-contract snapshot hash was updated twice, for the handle text and for the project arguments.

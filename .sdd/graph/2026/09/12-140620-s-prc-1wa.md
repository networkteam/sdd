SDD v0.18.0-alpha.1 is published at https://github.com/networkteam/sdd/releases/tag/v0.18.0-alpha.1, tagged on commit `d91c3643`, and it is the first release with no skill-driven flow to fall back to.

It is an alpha rather than a patch on v0.17.0 because the span breaks the MCP tool contract, the search API and the application composition, and an alpha rather than the stable because the retirement plan (20260821-123832-d-tac-ip1) still has open criteria. The retirement slice (20260912-135329-s-tac-7h8) was cut into this alpha rather than held back, on the reading that an alpha without the legacy skills is what produces the parity evidence the transition directive (20260820-162456-d-tac-o2v) waits on, and that its gate is on the stable.

Both additions the release placement (20260902-113959-d-tac-p28) named for v0.18.0 ship here, the disconnect fix and the multi-project wrapper, so this is the prerelease that directive said a waiting consumer needs. Its clause about the capability implementation plan is untouched: the capability rebuild landed without a separate plan entry, leaving unsettled whether that clause is satisfied or simply overtaken.

The prerelease flag survived GoReleaser, the first prerelease since that was set to `auto`, so `releases/latest` and the Homebrew cask stayed at v0.17.0.

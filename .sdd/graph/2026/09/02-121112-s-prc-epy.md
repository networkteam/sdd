SDD v0.17.0 is published at tag `b569dcf6`, the first stable release since v0.16.2 and the one that recommends the engine as the way to work. Its notes cover the whole span across the five prereleases from alpha.1 to beta.1, since a stable carries everything since the previous stable. The binary is identical to 20260901-221547-s-prc-qjj: the four commits between that beta and this tag are all graph entries. Workflow run 33616713194 published four platform archives, checksums, build provenance and `install.sh`, and this release carries no prerelease flag, so `releases/latest` and the Homebrew cask both moved to v0.17.0, where every prerelease had deliberately left them at v0.16.2.

Two scope calls were settled while cutting it. The `ProcedureRegistry` unexport that beta.1's notes announced as still to come before v0.17.0 has not shipped, because it is bound to the CLI-onto-application migration (20260901-192114-d-tac-wuy); Christopher first chose to drop the disclosure and then reversed, so the note ships in the stable notes retargeted at v0.18.0, keeping the do-not-build-against-it line rather than letting a consumer discover the break unannounced. The writing-guide quote-misattribution gap (20260901-220355-s-tac-owp) ships open and is deliberately absent from the notes, being outside the committed scope.

Drafting the notes needed one full compression pass. The first draft reproduced all five prereleases at close to their original length, at 18.5KB; Christopher rejected it as book-length, and the shipped set is 11.4KB, with the highlights merged from twenty-two down to fourteen. The release skill states how a stable's span is assembled but nothing about compressing it, which is why the first attempt defaulted to concatenation.

The README was then synced to the engine flow in commit 659f5bc8, which lands after the tag and is therefore not in v0.17.0. The move list, the capture description, the plan section, the multilingual section, the agent table and the layout section all still described the retired skill flow, one of them pointing at a bundled path that no longer exists; the commit carries the detail. This completes the README half of the v0.17.0 deprecation commitment (20260820-162456-d-tac-o2v), whose v0.18.0 removal stays open.

**Evidence.** The release is at https://github.com/networkteam/sdd/releases/tag/v0.17.0.

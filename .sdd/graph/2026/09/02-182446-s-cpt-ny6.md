The application resolves a principal's participant before the project is known, so a composition in which one person appears under a different name per project has no seam to say so.

Observed in the first external composition of the exported application, a hosted server where one account is a member of several projects and a membership may carry its own participant name. `AccessResolver.ResolvePrincipal` takes only the request identity and fixes `Principal.Participant` there; the application consults the resolver about the project only afterwards, through `ResolveProject`, which returns a runtime shared by every member. That participant then feeds session framing and stored session metadata, entry authorship, and WIP markers. The local `sdd serve` never notices: one process serves one project, and its resolver returns the configured name for it.

Expected: the participant applies per project. The split-authority gap that shaped the current contract already said so (20260713-163153-s-cpt-94l): the hosted resolver maps request identity to the user and applies that user's per-project participant override, else their user-global canonical participant. Its closing remediation made the request-resolved principal the sole authority and removed the runtime fallback (20260713-235631-s-tac-ym0), and the contract it left resolves the participant from identity alone; the per-project half of that expectation went unbuilt.

The deviation: the participant is a function of subject and project, and the contract offers only the subject.

Reasoning from the dialogue, marked as such: the external composition proposed an optional interface the application would consult when a resolver implements it. Weighed against it, a required resolution once principal and project are both known, because an optional interface is a hidden contract — a composition that omits it authors entries under the wrong name and nothing tells it. Compatibility of the exported surface carried no weight: the shape is chosen for the compositions that exist, which are all under our control.

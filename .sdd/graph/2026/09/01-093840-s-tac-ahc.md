The provider and model evaluation across the three chat purposes is complete: nine candidate identities ran the live pre-flight, writing-guide, and summarize eval suites with capability, timing, and token usage recorded per identity, and the full comparison stands in [the attached matrix](./01-093840-s-tac-ahc/model-eval-matrix.md).

The work landed on main in commits 3e8138b9 and 19c40958 (eval-harness usage recording and candidate selection, including the repair of the pre-flight eval suite the first smoke found broken), 5281444a (summarize eval with a fixed-configuration LLM judge), and 3a004f70 (summaries follow the configured graph language; the template's follow-the-entry's-language rule was an artefact); fork pins ec285f28 and 98555040 carry networkteam/gollm fixes 6a4e737, bc44234, and f6f84ac for the gpt-5-class temperature rejection, OpenAI cache-read usage, and the Anthropic effort mapping.

Headline findings: gpt-5.6-luna at default effort is the only candidate passing pre-flight 37/37 and the writing guide's anti-find-something invariant, at roughly a tenth of Anthropic cost. The incumbent claude-sonnet-4-6 was outperformed on its own tuned prompts (34/37); claude-haiku-4-5 is disqualified (29/37, invents facts). glm-5.3-flash:cloud at think=low is the fastest identity on every purpose (pre-flight P50 1.4s) and the best sampled summarizer (15/18 judged runs, no language drift in any), with measurable wobble in judgment tasks: one real defect missed across 37 pre-flight cases and a spurious minor finding on a clean draft about one run in three. The comparison supports recommending glm-5.3-flash at think=low for all three purposes on an Ollama Cloud subscription — fastest on every purpose at no per-token cost (usage-capped, with the cap generous at this usage profile), with the wobble named above as the known trade; the matrix stands as the model-recommendation baseline for sdd users and as the template for evaluating future models.

Deviations and experience: glm at default effort (max) ran as a timing probe only — the over-200s calls from initial use did not reproduce (worst 44s), but it burns around 1.2k output tokens on a trivial summary. Reliability was read from eval results rather than recorded rows, as the activity committed: semantic failures — empty output, wrong language, unusable JSON — fail tests or the judge. The sharpened summarize contract (a standalone, terse first sentence) proved a bar every model wobbles against, which reads as summarize prompt-tuning work as much as a model ranking. Surfaced beyond the comparison, to capture separately: the configured graph language reaches each LLM surface by a different route (pre-flight checks it, summarize now follows it, the writing guide ignores it), and acting per purpose on a future selection needs the per-purpose runner mux the LLM boundary architecture (20260830-234501-d-cpt-q6n) anticipated.

Commits 71ec470f and a2975099 deliver the session-port codec removal (20260901-185510-d-tac-8js) and the exported-surface cleanup (20260901-185116-s-tac-ah2): `SessionMetadata` no longer carries `CodecVersion`, and every exported `pkg/` signature resolves to public types under a new boundary test.

The codec half landed as committed: the field is gone from the port type, the engine's create site, and the local adapter's fallback stamping; the metadata fail-closed check is removed while the event-codec checks stay; the mixed-version constraint is documented on the `SessionStore` interface; and the adapter's read-compatibility held without migration — stored lines carrying the old field still decode through the deliberately lenient path, and the fail-closed test now asserts on an unsupported event codec instead.

The surface half moved the shared data types into a new dependency-free `pkg/application/types` leaf (budgets, serve lanes and sizes, lint vocabulary, focus fields, warnings), with the internal packages aliasing them so no call site changed. The boundary test loads `pkg/...` via `go/packages` (adding the official `golang.org/x/tools` module, test-scope) and fails on any exported signature or field naming an internal type; in its first run it caught three leaks beyond the gap's list — `GraphHealth`, `HealthIssue`, and the staged-attachment edit's patch pair — which moved with the rest. `ProcedureRegistry` remains the one allowlisted exception, named and governed by 20260901-192114-d-tac-wuy until the CLI write and lint paths move onto the application.

Vision diagrams will preserve Astro 7’s Sätteri Markdown processor while using one shared DiagramFrame component for wide inline presentation and accessible focused reading. They will keep the page table of contents and readable prose width unchanged, break out of Nova’s 50rem prose column only into the safe space available inside the main pane, stop at a tunable maximum width, and retain horizontal scrolling where a narrow viewport cannot show the SVG legibly.

The shared DiagramFrame component will own the borderless figure, caption, breakout sizing, zoom trigger, and native-dialog lightbox for the landscape map, collaboration view, work-lifecycle cycle, and before-and-after diagram. It will support clicking the SVG or an explicit keyboard-focusable control to open, Escape and backdrop click to close, focus restoration, background scroll locking, and reduced-motion preferences. Each diagram will supply only its SVG, accessible label, and caption, so interaction and layout behavior are implemented and tested once rather than duplicated four times.

This directive supersedes the Vision diagram presentation directive (20260818-194708-d-tac-qpf) because its selected starlight-image-zoom path cannot initialize with Sätteri and currently has an open compatibility gap. Switching the whole documentation site to Astro’s older Unified processor solely for component-authored inline SVGs would broaden the change into the content pipeline. A processor-independent shared Astro component keeps the newer Rust-based default and confines the maintenance surface to the behavior these four diagrams actually need. No current alternative Starlight zoom plugin with Sätteri support was found; a general modal dependency was considered but would still require diagram-specific adaptation.

This directive is fulfilled when all four Vision diagrams use the shared borderless frame, remain within the main pane with prose and the page table of contents unchanged, open through the shared native dialog with the stated keyboard, focus, scrolling, backdrop, and motion behavior, and the Sätteri-based website build and rendered navigation remain sound.

The binary's configuration messages now lead with `sdd config set` and name `.sdd/config.local.yaml` only as the per-machine override, shipped in commit 8cb24290 and closing the config-messaging gap (20260710-144212-s-tac-z7j).

The embedding-provider errors (embed factory, vector and hybrid search) point at the user-global `sdd config set embedding.provider`, and the LLM API-key error points at `sdd config set --local`, since keys belong out of version control per the README's placement story. Two stale code comments naming the local file as the selection mechanism were updated alongside; the overlay documentation in the config packages already described the layering correctly and stands.

One part of the gap's named scope is deliberately not delivered: the skill-template lines. The transition directive froze the legacy skill prose for v0.17.0 and schedules those renders for removal one release later (20260820-162456-d-tac-o2v), so editing them now would break the freeze to fix text that is about to be deleted. The gap closes on the binary's own messaging, which was its substance; the template lines expire with their files.

With this, both direct fixes the release focus carries are delivered (20260824-093559-d-tac-onl).

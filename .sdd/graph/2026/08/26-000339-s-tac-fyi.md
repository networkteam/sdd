Engine responses should repeat nothing the agent has already been served in this session; capture's play-back instead returns the draft's full text after every edit, so context fills with material the agent itself just sent and every round costs it processing time for text it already holds. The served-once memory is the mechanism meant to prevent exactly this, and it misses here because it dedups on byte identity — a revised draft legitimately differs, so an iterating capture falls outside it entirely (20260705-010751-d-tac-dbk). Much of what a round carries is unchanged, in the extreme a whole draft for a one-character edit; the measurement sits in (20260825-234504-s-tac-jro). The cost compounds with every round and every capture a session holds.

The procedure already carries the principle on its other face: play-back's own instruction tells the agent to show the user a delta after an adjust, re-showing the full description only when the body changed since they last read it. The deviation is on the serve, not in the guidance — what reaches the agent is whole every time.

It is not a member of the duplication constellation in (20260811-164958-s-tac-9l8), which a finer-grained hash would reach and this would not; and it runs against both (20260811-232108-s-tac-kus) and the play-back criterion in (20260821-105247-d-tac-q1x), each of which puts more on this step per round.

Recorded as reasoning rather than finding, one candidate from the dialogue: answer with a diff from the previously served body to the new one — smaller than the full text by definition whenever only part of it changed, and empty when only other fields moved. Anchoring that diff on what the engine last served this connection, rather than on what the agent last reported, keeps the base a fact the engine owns while every byte the agent has not seen still arrives in full. What it spends is the verification contract — the user would confirm text the agent reassembled from a patch rather than bytes the engine rendered — and nothing here settles whether that trade is acceptable.

Vision diagrams will preserve the page table of contents and readable prose width while breaking out of the prose column into the safe space available inside the main pane, capped at a tunable maximum width, and opening in an accessible lightbox for focused reading. This refines the active Vision landscape plan (20260818-133112-d-tac-okx) after the first delivered slice (20260818-190009-s-tac-8db) exposed a presentation gap: Nova's 50rem content column and the diagrams' card padding shrink 920-unit SVGs until their smallest labels render around 8px.

The implementation will keep ordinary page prose and the right-hand table of contents unchanged. A shared borderless diagram frame will own the breakout width, caption, and narrow-screen horizontal scrolling, staying within Nova's clipped main pane rather than overlapping navigation. The precise maximum width is a rendered tuning value, not a site-wide content-width override. This keeps the docs site's visualization principle (20260715-181235-d-tac-c7b) from making prose harder to read in order to make visuals easier to read.

Focused reading will use the compatible starlight-image-zoom plugin with its explicit Zoom wrapper directly around each inline SVG. That path supplies native-dialog behavior, viewport scaling, focus restoration, and reduced-motion handling without making the project own a custom modal implementation. Automatic image discovery is not relied on because the current SVGs are nested inside Astro components. A local alternative built from an Astro script that clones each SVG into a hand-made overlay was considered and rejected because it opens an ongoing accessibility, navigation, scroll-lock, and browser-behavior maintenance surface; the attached research records both options and the implementation evidence.

This directive is fulfilled when all four Vision diagrams use the shared borderless frame, remain within the main pane with prose and the page table of contents unchanged, and open through the explicit SVG zoom path.

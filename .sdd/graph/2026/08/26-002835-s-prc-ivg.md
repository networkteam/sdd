The kind guidance asserts that one test always settles a contest between two kinds, and for fact against done that claim is too strong: the territory genuinely overlaps, so the test on offer yields a confident wrong answer where it should yield a flagged judgment call. Asked whether the world changed or only what is known of it, an evaluation answers *only what is known* and routes to fact (20260818-120000-s-prc-dsc), while the evaluate procedure fixes every evaluation as a done (20260703-200000-d-prc-evl) — and the exemplar the guidance offers for a fact is itself a measurement, a coffee lot's cupping score. The same one-test-settles-it claim stands in the type-system overview (20260812-180000-s-prc-typ). Observed directly: from the served guidance in this session the drafting agent proposed fact for a run measuring the framework's own serve behaviour, and the correction came from the user (20260825-234504-s-tac-jro).

The overlap is not an edge case. One event is commonly both: user feedback on a released version is knowledge later work can cite and a thing that happened at a moment, and no phrasing of the question separates them, because both readings are true at once. Two candidate criteria were tried in the dialogue — how volatile the observed subject is, and whether the observation came from outside the project or from the project working on itself — and each looked decisive against a chosen example, then dissolved against the next.

What survives is structural rather than semantic, and it does not decide: a done is required to point at what it completes and lives in the project's account of its own activity (20260812-170000-s-prc-dnk), while a fact sits off the attention surface and is cited as a premise (20260816-110000-s-prc-kno). Which of those an entry is for is the actual question, and it was settled here in dialogue rather than by a rule — the user's position being that it can only ever be settled that way, or on what the entry is to be used for.

Resolution is checkable: the guidance no longer offers a deciding question for this pair, but names the overlap, says what tips it either way, and routes the call — so an agent meeting it raises the choice instead of answering it.

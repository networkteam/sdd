The capture writing guide judges kind-shaped drafts while being told nothing about the kinds. Its entire prompt is the general entry-craft criterion, five axes, an output format and a calibration paragraph; on framework vocabulary it carries one line asserting that kinds, layers and refs are assumed known. The draft it receives names its type, layer, kind and intent, and lists each ref's kind, as bare tokens with no definitions anywhere — so every judgment about whether a draft is the right shape for its kind rests on the model inferring a taxonomy it was never given.

The capture-guide architecture already specifies otherwise: the guide's context is the draft, the entry-craft criteria, and kind-specific style instructions (20260810-141555-d-cpt-20r). That third element has never existed, and neither has any statement of the kind system it would rest on — what the kinds are, what each is for, how they connect. The obstacle is not mechanism: the same codebase's other capture-time checker already renders graph-sourced vocabulary and standing constraints into its own prompt.

Six runs of the live guide over two done specimens show the inference happening rather than the knowledge being used — one run concluded a closure edge was absent because the ref list held only other ref kinds, which is reasoning from token shapes — and the same input produced five, four, and two findings across runs, the instability this absence would predict (record kept at 20260811-174502-s-cpt-ayb). The guide has been shipping and judging real captures throughout (20260811-154427-s-tac-yzg).

The knowledge is already committed, one consumer short. An active plan ships an indexed overview fact for the type system plus an unindexed detail fact per kind, and gives every capture lane a pointer to its detail fact (20260726-193730-d-tac-zrh) — all of it aimed at the drafting agent. Nothing makes the checker a consumer of that same pool. This is the checking-side twin of the composition-knowledge gap already recorded for the drafting side (20260722-141659-s-cpt-rza).

The `sdd config` surface was rounded out in one review pass: `sdd config unset` added (commit 339d580b), `sdd config get` widened to accept a subtree prefix or no argument for the whole merged view (716cbf8e), and the provenance table made safe for multi-line values by escaping line breaks (0b95436d). Unset mirrors set — user-global by default, `--local` for the machine file — removes keys with comments preserved, and errors on a key that is not set. Get keeps the script-friendly bare value for an exact single-key hit and renders everything else as the provenance table; secrets stay masked at the model layer on every surface.

The same review simplified the messages the config-messaging delivery had just introduced (20260828-162042-s-tac-9xx): the embedding and API-key errors now name just the command, since it defaults to the user-global layer on its own, and the keys-belong-local advice was dropped from the README and config comments — the user-global file is equally uncommitted, and one global key serves every project (commits a3cbf8c5, caad2513, 8b5e86a5, 6f863811).

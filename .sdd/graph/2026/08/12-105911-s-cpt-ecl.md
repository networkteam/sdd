An over-specific number left in an entry — a count, a duration, a line count — does not merely dilute it, it binds every future reader, because an entry offers no way to tell which of its specifics are load-bearing, so a later session must honour all of them. The entry-craft directive (20260810-121912-d-cpt-7zr) already rules that a figure belongs in the body only when it is the claim itself, and states the cost as evidence crowding out the principle through restatement. The heavier cost is downstream and immediate: a commit hash and a line count sit in the same prose with the same authority, so when the code no longer matches the number, that mismatch reads as signal — worth investigating, possibly worth capturing as a gap — all to reconcile something that never carried meaning. Silence would have left that reader better off, which makes residue negative content rather than filler to trim for length.

The discriminator is work, not durability. Counts, durations, line numbers and sizes belong in a body only when they are part of the meaning: a commit hash earns its place because it is how the reader reaches the evidence, while a line count earns none, because no decision the entry supports turns on it. Residue is what survives when an author writes up how they checked rather than what they concluded, so it collects wherever an entry reports its own checking — the passages where the author's working notes are closest to hand and feel most like proof.

The failure is most attractive from inside a done. 20260811-160518-s-cpt-igk establishes a done's provenance and evidence as its own load-bearing content — true of pointers, and not extending to measurements. Both specimens are dones: on 20260811-234201-s-tac-dq7 the writing guide flagged the transcript counts correctly and the drafting agent dismissed the finding by citing igk; on 20260812-000034-s-tac-i5x the guide did not fire and the user caught the line counts at playback. The directive was served in full at session open both times, so serving the rule is not sufficient — what was missing was its cost, and a checker that fires inconsistently on this axis cannot supply it.

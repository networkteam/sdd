The writing-guide and pre-flight prompts now teach standard JSON escaping through one shared static partial, shipped in commit 15840688, closing the gap where the writing guide emitted unparseable JSON for drafts containing an ASCII double quote (20260827-224853-s-tac-giv). Both output-format blocks include the new `json_string_rules` partial in place of their per-prompt avoidance rules, which banned the literal double quote without ever naming the backslash escape. The excerpt-citation style rule (single quotes or backticks) moved into the partial too; drafting surfaced it as the same rule stated separately in each prompt, differing only by field name. The partial renders static text, so both system blocks remain byte-stable cacheable prefixes, and regression tests pin the rule's presence and the avoidance wording's absence in every system template on both paths. This delivers the first of the three scope additions committed for v0.17.0 (20260828-145055-d-tac-ruz); the ref-kind vocabulary fact and the pre-flight migration onto it remain open there.

## What shipped

`internal/mdcompose` is the reusable transform the heading-hierarchy rule (20260810-163617-d-cpt-5wv) asked for: it shifts a fragment's headings so the shallowest lands at a target level with relative order preserved, clamps at the ATX floor rather than emitting a seventh hash, and never promotes a fragment that already sits deeper. It is fence- and indented-code-aware, and deliberately leaves setext underlining alone — served fragments are authored ATX throughout, and rewriting an underline would mean rewriting two lines on a guess about which is prose.

`as-bodies` is its first consumer: per entry an identity header — full ID plus the layer/kind/type words, and no summary, since the summary derives from the body already being served — then the body demoted one level below that header. A body opening with a heading contributes it as the entry's title with the identity line as byline; a body opening with prose takes the identity line as its header. The render carries its own result shape rather than reusing the flat list, which is what makes the existing render-shape checks reject `group`, `expand(refs)` and `expand(involvement)` against it for free; `brief` is rejected explicitly as meaningless for a body render. Selection, ordering, and capping stay with the grammar, so the render added no selection vocabulary — the dedicated inject function the plan weighed and rejected would have duplicated it.

The fact ships embedded with no participants, no project refs, and no index enrollment: its words are pushed in full at every open, so advertising them as a pullable reference would point an agent at what it already holds. The shell (20260704-100000-d-prc-dlg) declares the lane first, which is what primed-rather-than-pulled means positionally — after the engine's info block, before the process core and the move enumeration. The lane ships uncapped on purpose: a `maxBytes` cut would truncate the posture mid-sentence, so the guard against the measured host output budget (20260719-122103-s-tac-jom) is keeping the principles set small, not capping it.

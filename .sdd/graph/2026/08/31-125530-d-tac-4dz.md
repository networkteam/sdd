The sdd MCP server returns tool results as `structuredContent` only; the backwards-compatible text mirror in `content` becomes opt-in behind a `--compat` flag on `sdd serve`. The projection fact (20260816-205521-s-tac-x9l) recorded the option space and left the choice open. Two inputs settle it now. First, the bounded-serves live verification on Codex CLI produced the primary evidence that fact lacked: both copies can reach the model. The door, catch-up compose, and engage brief serves each arrived as a roughly 60KB envelope holding the payload twice, about 15K tokens against the harness's ~10K-token default budget (20260719-122547-s-tac-40d), so every large serve arrives middle-cut unless the agent raises its wrapper's print budget. The single copy, around 30KB, fits. Second, renewed cross-client research ([research record](./31-125530-d-tac-4dz/mcp-token-doubling-research.md)) finds the doubling independently reported (Blockscout's MCP server issue: ChatGPT Apps and other emerging MCP consumers pass both fields to the model) and names the clients that read only `content`: Cursor silently drops structured-only results, VS Code errors on them, LangChain hides `structuredContent` from the model.

Dropping the mirror by default, without a summary stub in its place, is a deliberate narrowing. sdd's serves are instruction-bearing wholes, a stub would be a second representation to maintain, and no content-only client consumes the sdd server today. Adoption runs one harness integration at a time; supporting a content-only client is a valid concern to be driven by real usage and evaluation, and `--compat` restores the spec-recommended mirror per registration when that need arrives. The go-sdk synthesizes the mirror only when `Content` is nil, so the change is a result-construction seam in the server, not an SDK fork. This augments the bounded-serves plan (20260829-173342-d-tac-rzi): with the doubling gone, a single-copy serve sits under the ~10K-token host floor and the plan's live-verification criterion becomes achievable without recalibrating the measured budget.

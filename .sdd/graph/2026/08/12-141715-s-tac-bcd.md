The shell's framing bundles aspirations, guiding directives, focus, and participants into one declared lane, so the per-lane served-once dedup re-serves all four sections whenever any one of them changes — repaired by splitting the declaration into one lane per section, giving each its own hash. The dedup unit is coarser than the change unit, and the framing's most stable content rides along with every change to a volatile sibling.

**Target.** Served-once dedup is committed: identical rendered blocks are stubbed, changed content serves in full (20260705-010751-d-tac-dbk). The framing composer honors it per lane — it returns lanes as separate blocks so each dedups on its own, stating the intent that a graph write changing only the recent-moves lane re-serves that lane alone, never the stable aspirations or directives.

**Actual.** Observed live at a session's concluding serve: a supersede written mid-session re-rendered the focus section, and because focus shares its declared lane with aspirations, guiding directives, and participants, the entire block re-served although none of the other three sections had changed. The same serve correctly stubbed the working-principles lane and the info block — each its own lane, unchanged — so the mechanism works exactly at the granularity it is given.

**Mechanism.** The user-dialogue shell declares three framing lanes: the principles selector, one view pipeline joining aspirations, guiding directives, focus, and participants into a single rendered block, and the byte-capped recent-movement lane (20260704-100000-d-prc-dlg). Dedup hashes whole blocks, so joining sections into one pipeline makes the block's volatility the union of its sections' — focus moves with nearly every working session, while aspirations change rarely.

**Where it sits.** This is the volatile-mixed-with-static duplication class already recorded for injected step views (20260811-164958-s-tac-9l8), surfacing in the shell's own framing lanes — the very blocks the dedup was built around. The repair is smaller than that gap's render-level direction: no renderer or hashing change is needed, only the shell's declaration split.

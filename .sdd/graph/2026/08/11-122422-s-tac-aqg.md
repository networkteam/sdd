Outer validation confirms the working-principles feature (20260811-120317-s-tac-zhw) delivers in real use: on a client restarted against the rebuilt binary, the posture arrived unprompted and complete at session open, ahead of every graph-structure lane — the one claim the test suite structurally cannot make. Scope was deliberately the outer lens alone; inner verification is already carried inside the closing done (clean vet, tests, lint, plus render- and serve-level tests), so re-running it here would restate rather than judge.

## What was observed

Christopher restarted the client and asked whether the priming was visible — an unrehearsed open, not a fixture. The framing came back in order: engine info block, then the principles lane with all six principles complete and byte-identical to the authored source, then aspirations, guiding directives, focus, participants and recent movement. His own read of the result was the attestation. Two properties beyond the acceptance criteria showed well. The served identity line makes the priming actionable rather than anonymous — an agent that wants to question or override the words can pull or supersede the exact entry, which matters precisely because primed content arrives unasked for. And the cost is small in practice: the lane measures 2,846 bytes against the door's 25KB contract, so the small-set discipline the design leans on is cheap to hold rather than already strained. Session state also survived the server restart intact, exercising resume fidelity incidentally.

## What stays unjudged

This validates that the mechanism delivers the words, not that being primed counters the slot-filling bias the posture exists to counter (20260810-123226-d-cpt-ei0) — that is a behavioural question across many sessions on varied work. Foreign-host behaviour is also untested; the run was same-host Claude Code only. And the run only partly meets the standing rule that agent-facing surfaces be validated by an agent session not shaped by whoever built the change (20260716-155256-s-prc-686): a real agent drove the real integration over MCP, but that agent implemented the feature, so it inherits the implementer's assumptions where a foreign reader would bring its own.

No findings. Nothing in the run surfaced a defect, and the gaps above are the declared scope rather than discoveries — recorded as clean coverage instead of inventing a finding to justify the pass.

An agent capturing through the engine has no served text telling it how to reference a staged attachment from an entry body. Observed while fixing the attachment-link false positives (20260827-232249-s-tac-pxn) by sweeping the surfaces an engine-driven agent reaches: the staging tool's description ends at passing the handle back in the report's attachments field, the capture procedure's assemble step says to stage the record and list the handles and stops there, the reading tool instructs the agent never to derive storage paths, and the kind facts that mention attachments say what they are for without giving any syntax. No base fact covers attachments. The `./27-234805-s-tac-03e` placeholder is written down in one file, the legacy skill's CLI reference, which v0.18.0 removes (20260821-123832-d-tac-ip1).

So the engine supports a link it never teaches. The capability is live on this path, since slice two made draft-to-entry assembly resolve the placeholder (20260826-230218-s-tac-7yr).

The effect is visible in the graph. Before the engine most entries carrying an attachment linked it from the body; since then almost none do, and in the latest stretch none at all. The genre did not change: design records and evaluation notes were linked before and are not now. Nor is the result the failure the write gate watches for, which is a body claiming a record it does not point to. The unlinked bodies almost never mention their attachment at all, and the pre-flight attachment-claim check exempts that case by design, so nothing reports it. The counting establishes the timing, not the mechanism, which rests on the inspection above.

Recorded as reasoning rather than observation, two candidates stand side by side. The assemble step already carries attachment guidance and stops one sentence short of the syntax, so finishing it there opens no new knowledge home. The alternative ships it as a base fact under the pull layer (20260707-140544-d-cpt-dtv), the route taken for the view grammar (20260717-095714-s-tac-lwi). What separates them is whether one line of syntax is authority that must live in one place, or the tail of an instruction that already exists, a line the teaser directive draws at authority rather than wording (20260730-110228-d-cpt-rh6).

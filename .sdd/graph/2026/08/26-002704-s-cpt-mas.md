The agent proposes an entry constellation — which entries to write, their kinds, and the references between them — without knowing the ref-kind vocabulary, which no surface delivers before the structure is already fixed.

Observed twice. In a session in another project, the agent laid out a four-entry structure and drew its edges as `caused`, `closed-by` and `motivates`, none of which exist in the vocabulary, then put that structure to the user for approval as the shape to capture. The user supplied the real vocabulary by hand, pasting the table from the legacy skill reference, and the structure was redrawn. That session's read record shows how it happened: every entry read before the first capture was project content, and the type-system overview first appears as an injection by the capture step — after the structure was set and approved — with the selected kind's authoring fact right behind it. No framework fact was pulled while the structure was being decided. The second instance is this session, in this repository: the agent proposed a four-entry structure with kinds, layers and reference kinds across three turns, pulled the kind-discrimination fact only after the user challenged a kind, then the gap authoring fact only after the user challenged a framing. The facts were named in the opening serve and one call away throughout.

Expected: framework reference knowledge is reachable at the moment it is needed. The teaser contract (20260730-110228-d-cpt-rh6) fixes the standard any pointer to it must meet; the pull-layer directive (20260707-140544-d-cpt-dtv) commits base facts as its reachable home. Neither reaches this moment. The ref-kind taxonomy is one of the items the push-only gap (20260707-135618-s-cpt-7wc) named as homeless and it remains unbuilt, so there is no fact to pull — and nothing at structure-design time would trigger the pull if there were.

The deviation is one of timing, not of vocabulary quality. Structure design is where reference kinds are actually chosen, and no framework knowledge reaches that moment. Capture does serve a condensed vocabulary at its drafting step, but that is downstream: by then the constellation is fixed and each capture sees a single entry, so the serve can only tag edges someone else already drew.

Candidates, unsettled: ship the ref-kind vocabulary as a base fact, which the pre-flight gap (20260824-165218-s-tac-7w6) needs independently; point the type-system overview at references, which today describes entries, kinds and layers without mentioning that entries connect at all; give the dialogue level a cue that naming a structure is a decision point, since a fact nobody pulls is still not read.

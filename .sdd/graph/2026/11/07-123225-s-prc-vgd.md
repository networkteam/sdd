SDD v0.18.0-alpha.3 is published at https://github.com/networkteam/sdd/releases/tag/v0.18.0-alpha.3, tagged on commit `4ce218e0` as the third prerelease of v0.18.0.

Since v0.18.0-alpha.2 (20261001-110606-s-prc-p5e) it ships four deliveries: participant lists in engine capture (20261106-175340-s-tac-8pw), structured output for pre-flight and the writing guide (20261102-193234-s-tac-vyd), typed repository identifiers with the declared dependency closure as the horizon of every read (20261029-140922-s-tac-0cb), and the actor chain merge fix (20261026-174647-s-tac-fwo). It also ships the experimental `sdd export` command from pull request #22, which no graph entry records. The notes add three breaks, CLI reads narrowed to the declared dependency closure, pre-flight and the writing guide requiring an endpoint that enforces the response schema, which Ollama Cloud does not (20261101-002900-s-tac-3q0), and `RepoID` in the exported Go API, and repeat the breaks of alpha.1 and alpha.2. It stays an alpha because the span breaks the Go API again and the stable's gates are open: the bootstrap parity verdict (20260726-195300-d-tac-fim), kind-capture test coverage in the skill retirement plan (20260821-123832-d-tac-ip1) and the getting-started docs (20260821-181419-d-tac-hq1).

In the doing: the Homebrew cask quarantine fix from pull request #25 (`da83483e`) is left out of these notes because a prerelease does not update the cask, so the stable's notes carry it. `git fetch --tags` refused to overwrite the local tags v0.1.0 to v0.3.0, which differ from the remote ones; this release does not depend on them.

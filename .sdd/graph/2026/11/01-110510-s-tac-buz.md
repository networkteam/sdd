This covers the structured-output plan (20261031-141038-d-tac-p8l) except its closing steps, the merge and closing GitHub #20 and #21, so the plan stays open.

**Delivered.** In sdd: `4fb9af75` format evals over a hostile-character example set in data files, with #21's cases anonymized; `55186d3f` `ResponseSchema` on `pkg/llm.Request` and the adapters (Claude CLI `--json-schema`; strict `response_format`, `output_config.format` and `format` through the gollm fork; `llm.endpoint` for the anthropic provider); `62cec3f9` the schemas as ordered JSON files, prompts without JSON construction rules, quotes that only locate their passage; `dca0a76b` capture's instruction to locate the passage from a quote; `0421a997` and `d332ed4b` the format-evals workflow; `b12440f6` and `58607295` the cost Opper reports, in usage and eval results.

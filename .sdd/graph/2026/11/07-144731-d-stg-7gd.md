SDD is positioned as a new way of working for people and AI agents on a project, with the graph as one part of it: the agent-native memory of the whole project and, through the procedures it holds, part of the process itself. Public material leads with the way of working and its why, and introduces the graph after it.

The positioning carries five points, in this order:

- Why now: agents have changed the speed of work, code above all, and the decisions and shared understanding behind that work have to keep pace and scale.
- People make the decisions and understand and shape the why behind them, with agents helping at every step.
- The belief behind it: this lets people and agents do better and more autonomous work (20260422-123814-d-stg-7lu).
- Knowledge builds up while working with agents through SDD, not as a separate documentation step (20260422-124325-d-stg-2wb), and dialogue among people, such as a meeting or a chat, can be distilled into the graph the same way.
- The graph is information and process at once. It acts as agent-native memory for the whole project, so every person and every agent starts from what was decided and why. It also shapes the work: the procedures the agent follows are graph entries a project can adapt, and rules are planned to join them, so the graph holds active components beyond knowledge.

The current wording opens the README and the docs page "What is SDD?" (`website/src/content/docs/what-is-sdd.md`).

This retires the one-liner of 20260717-105901-s-stg-miu, which led with "agent-native memory" as the category prospects search for. Christopher rejected that lead while reviewing the docs written for 20260821-181419-d-tac-hq1: SDD is a memory, a brain or an LLM wiki only in part, and leading with memory files it among those tools and hides the way of working, which is the larger part. The speed argument follows 20260420-163043-s-stg-ljq, which already read accountability that cannot keep pace with AI-augmented creation as a sharper value than memory across sessions. Public material that leads with memory, or presents SDD as a memory tool, breaks this directive.

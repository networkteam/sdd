**Responses and providers.** `55186d3f` puts the response schema on `pkg/llm.Request` and enforces it in every adapter: the Claude CLI through `--json-schema`, OpenAI through strict `response_format` on any base URL, Anthropic through `output_config.format`, Ollama through `format`. The gollm fork, pinned at `698361b` (`b12440f6`), carries the schema on the regular request path, so the system/user prompt split and usage survive (`25ba06d`), sends the system prompt once and per call (`c460d23`), picks OpenAI parameters without model-name matching (`30e7a78`, `abc8552`), takes a configurable Anthropic base URL (`14f7165`, with `llm.endpoint` for the anthropic provider in `55186d3f`) and reports the provider's cost (`698361b`). `62cec3f9` declares both schemas as ordered JSON files, removes the JSON rules and the shared escaping partial from the prompts, and asks for a quote that locates its passage, with an example, for the writing guide and pre-flight excerpts alike; `dca0a76b` tells the capture agent to locate the passage from a quote.

**Deterministic tests.** Adapter wire tests with problem characters over faked provider responses (`55186d3f`), #21's parser cases anonymized (`4fb9af75`), prompt contract tests (`62cec3f9`) and a capture procedure test on quotes (`dca0a76b`).

Engine capture takes a stated participant list for an entry, delivered in commit 790d0b07 on `main`. The capture procedure collects an optional participant list at assemble and at every revise step, serves the local participant and the active actors with their aliases, and plays the list back. An empty list still writes the local participant. This implements the attribution rules of 20261106-174926-d-cpt-kx0.

- 20260911-125948-s-tac-9cs is closed: a participant list the user states now reaches the draft, revisions and playback, and the write path keeps it.
- 20261001-150924-s-tac-td3 is closed: the assemble gate and pre-flight no longer require an exact active canonical. They refuse only an alias of an active actor and name its canonical, and a name no actor declares yet passes. In the reported case, a capture that leaves the list empty still draws a high finding for the configured short name, now naming the canonical, and reporting the canonical clears it. Lint keeps warning about participants without an actor, which now marks an actor still to capture.

The same commit edits the actor kind's authoring fact (20260818-110000-s-prc-act) in place so an entry may name a participant before an actor declares them. Focus actors still have to be active actors; the change covers participants only.

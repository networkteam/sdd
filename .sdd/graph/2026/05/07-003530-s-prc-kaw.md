Two observations from a single explore session reveal that `/sdd`'s explore-mode flow misroutes both *what* the sub-skill does and *when* the playbook is loaded.

**(1) Stale semantic-search guidance.** The `/sdd-explore` sub-skill still uses the pre-search LLM-as-semantic-matcher recipe (Step 4: bare `sdd list` then agent reads through everything for conceptually related entries) despite `sdd search` having shipped (s-tac-96a) and the graph reaching 442 entries — the order-of-magnitude scale at which s-tac-2y8 explicitly flagged re-evaluation (then ~80). Live observation: the forked sub-skill ran `sdd list` followed by a cascade of grep narrowings (`grep -E "{status: (active|open)}"`, keyword greps for view/pipeline/catch-up/etc.) that semantically duplicate `sdd search --query` / `--term`. The skill prompt never mentions search at all.

**(2) Playbook-load-after-invoke ordering.** The outer `/sdd` skill invoked `/sdd-explore` *before* loading `playbook-explore.md`, contradicting the prose rule "Load the listed reference first, then invoke any named sub-skill." The mode table phrasing — `invokes /sdd-explore, then [references/playbook-explore.md]` — reads as a temporal sequence (invoke first, load reference after) and overrides the prose. The same structural issue applies to the Groom row. This matters because the playbook contains the briefing and dialogue instructions for the sub-skill's output, and may also condition how the sub-skill is invoked.

**Fix scope is skill prompts, not the CLI.** `sdd list` filters are already adequate (default open/active, `--type`/`--layer`/`--kind`/`--topic`). Touch points:

- `internal/bundledskills/claude/sdd-explore/SKILL.md` Step 4 — replace list-and-read with `sdd search --query` (primary), `sdd search --term` for known tokens, `sdd show --max-depth 0` to drill in.
- `internal/bundledskills/claude/sdd/SKILL.md` mode table — reorder Explore and Groom rows so the playbook reference is listed/loaded first and the sub-skill invocation second, matching the prose rule.
- `internal/bundledskills/claude/sdd/references/playbook-explore.md` — currently frames search as a supplement; should be the default related-entry mechanism.

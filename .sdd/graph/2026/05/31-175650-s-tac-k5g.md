Scoped both of `sdd`'s automatic git commits with an explicit `-- <paths>` pathspec so a dirty or pre-staged index can no longer leak unrelated work into a CLI-generated commit (closes s-tac-tdz). Changed `gitCommit` (init, new, summarize, wip start, lint fix, rewrite) and `gitRemoveAndCommit` (wip done) in `cmd/sdd/main.go` to pass the touched paths to `git commit`, and added regression tests that pre-stage an unrelated file, run each committer, and assert it stays out of the resulting commit while remaining staged — covering both the write path and the delete path (where `git commit -- <deleted>` must still record the removal). Verified with go vet, the full test suite, and golangci-lint. Landed on main as commit 4183cba.

Pin project as the default highlighted option in the `sdd init` Bubble Tea scope selector, sharpening AC 3 of the readiness-check plan (d-tac-kud) which specifies "default highlighted" without naming which scope. SDD-instrumented repos have `.sdd/` checked into the repository, so a contributor running `sdd init` after cloning is overwhelmingly likely to want project-scope skill installation; highlighting project minimizes friction on the common path while keeping global one keystroke away. The implementing agent should set the selector's initial cursor/focus to project — not just list it first — so the default-accept (Enter without arrow keys) lands on project.

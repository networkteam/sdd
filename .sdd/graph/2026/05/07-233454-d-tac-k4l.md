Re-promotes /sdd-catchup from playbook reference to a no-fork sub-skill that uses Claude Code's dynamic context injection syntax for data loading, while main /sdd injects always-on framing (status header, aspirations, focus, participants) via the same mechanism so every /sdd flow has project context regardless of mode.

The catch-up sub-skill carries the converged voice + format + render design produced through extensive paste-test iteration; main /sdd routes to it via the Skill tool when catch-up is the appropriate mode. Addresses the synthesis-bottleneck gap (s-cpt-jq7) by mechanizing the fetch step, brings the structural-injection pattern (s-cpt-k8i) into concrete use, and preserves the modularization decision (s-tac-bv9) by keeping voice/format guidance encapsulated in the sub-skill rather than inflating SKILL.md.

The design dialogue produced these artifacts: a tone-of-voice block (audience persona, mechanical swap table, judgment patterns, transformation examples, target-tone briefing from the Kōgen Coffee story); a format template (story-arc thread headers, narrative trails with inline IDs when entries are named, action-tight numbered items, A–E lettered drill bullets, italic focus summary at top, single open-question prompt); a fetch shape (just-landed, active-and-hot, open-and-warm via `sdd view` layouts plus `sdd wip list`); and a set of friction fixes from observing wall-clock cost across iterations (mechanical/judgment split for anti-patterns, don't-echo-entry-vocabulary rule, internal-references rule for slice numbers and AC numbers). See [catchup-design.md](./07-233454-d-tac-k4l/catchup-design.md) for the converged design as the literal paste-test prompt that produced acceptable output across multiple test runs.

## Acceptance criteria

- [ ] Main /sdd SKILL.md injects status header, active aspirations, active focus, and active actors/roles via `!\`sdd ...\`` syntax — small, always-on, project-portable framing for every /sdd flow.
- [ ] /sdd-catchup exists as a sibling sub-skill at internal/bundledskills/claude/sdd-catchup/SKILL.md.
- [ ] /sdd-catchup runs inline in the main session (no `context: fork`).
- [ ] /sdd-catchup injects the four catch-up data fetches (just-landed, active-and-hot, open-and-warm, wip) via `!\`sdd ...\`` syntax.
- [ ] /sdd-catchup SKILL.md carries the voice block as captured in the design reference (audience persona, mechanical swaps, judgment patterns, transformation examples, target-tone example, names-that-stay, test heuristic, aspirations/focus framing instructions).
- [ ] /sdd-catchup SKILL.md carries the format template, format rules, and don't list as captured in the design reference (story-arc headers, narrative trails, inline trail-IDs, A–E drill bullets, italic focus summary, sentence/item ≤15 words, no semicolons in body).
- [ ] Both skills declare `allowed-tools: Bash(sdd *)` so injected commands run without per-use approval.
- [ ] Main /sdd invokes /sdd-catchup via the Skill tool when catch-up is the appropriate mode.
- [ ] Aspirations, focus, and participants shape threading judgment in the catch-up but are not restated as content; focus surfaces only as the single italic line at the top.
- [ ] Output matches the converged design — verified by an evaluation session whose closing done signal records voice fidelity (no banned vocabulary), format adherence, threading quality, and wall-clock cost.

Agents with the /sdd skill don't establish alignment with the user — neither at the start of an interaction nor when shifting what they're doing next. The active-listen move is missing: restate what landed, surface relevant graph context, propose a way forward. Instead, the agent jumps straight to action or formal capture.

A second symptom points the other way: agents over-ceremonialize small requests, proposing new gaps and plans and "next session" for 10-minute work. Same underlying cause — the agent doesn't read the stakes, and skips the cheap alignment moves before committing.

Cheap alignment is restate + propose + check, not a negotiation. Full capture ceremony is the expensive form, reserved for things that belong in the graph. Direct action fits when stakes and intent are clear.

This extends s-prc-fc0's mode-table conflation insight, which already named the alignment check as "implicit in dialogue, never named." The new observation places that absent move at the earliest point — every new input and every transition — not just post-anchor.

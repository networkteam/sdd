Single-source the ref-kind vocabulary rather than restating it in each surface, refining d-tac-6d4's skill and rubric work. The eight kinds and their principle definitions live in one canonical fragment under the bundled skills. `sdd init`'s existing skill-render step (writeStampedEntry -> RenderSkillFile) resolves an include directive so the installed framework-concepts.md carries the vocabulary inline -- no go:generate. Pre-flight reads the same fragment from the bundled-skills embed and injects it into the ref-meta prompt, which then carries only the calibration and the status-distinction. Skill drift detection (SkillStatus pristine/modified) resolves the include the same way so classification and the content-hash stay correct. This answers the shared-canonical-reference question (s-tac-uer) for the ref-kind case and establishes a reusable include mechanism; broader definitional grounding under s-tac-uer stays open.

Extends `/sdd-catchup` with explicit expand-first drill behavior and adds a `refs-of(...)` filter to `sdd view`, so typing "drill A" surfaces the area's landscape in catchup register (numbered items, short trails) before the user picks an entry to engage on. Resolves the drill fall-through gap (`s-prc-bxk`), operationalizes the topic-drill directive (`d-tac-qom`) deferred from the catch-up sub-skill build (`s-tac-7uy`), and extends the `sdd view` pipeline (`d-tac-uww`) with a ref-graph traversal filter the pipeline currently lacks.

Drill expansion composes three mechanisms in parallel — outgoing refs of the seed entries (via the new `refs-of(...)` view filter), semantic search on the cluster's phrase (`sdd search --query`), and topic-filter on the cluster's label (`sdd view --topic`) — merged by entry ID, deduped against seeds, capped at ~10 entries total. The topic mechanism is silent on this graph until annotation backfill lands (`s-cpt-sy4`), but ships now so drill is ready when topics arrive. The catch-up render drops the "or survey" verb — `/sdd-explore` is engage's research tool, not a user-facing widening verb, so catchup's user verbs collapse to drill (stay in catchup, narrow on a cluster) and the implicit engage-on-entry the user invokes when they're ready to act. See [plan](./17-173733-d-tac-jqq/plan.md) for alternatives considered, implementation slicing, and evaluation approach.

## Acceptance criteria

- [ ] `sdd view` accepts a `refs-of(id1[,id2...])` filter primitive returning entries that are refed by ANY of the given IDs (outgoing direction). Composes via intersection with existing filters (`active`, `kind`, `layer`, `since`, `topic`, `not`). Tests cover single-ID, multi-ID, composition, and empty-result cases.
- [ ] `internal/bundledskills/claude/sdd/references/cli-reference.md` documents the new `refs-of(...)` filter in the `sdd view` pipeline section.
- [ ] `/sdd-catchup` SKILL.md adds a "Drill behavior" section specifying: seed identification from loaded catchup data, three-mechanism expansion (`refs-of` filter via `sdd view`, `sdd search --query`, `sdd view --topic`), merge by entry ID, dedupe seeds, cap at ~10 entries total. Layout strings appear verbatim in the skill so the agent has no inference burden on the CLI shape.
- [ ] Drill renders in catchup register: same voice block (no banned vocabulary), numbered items with ≤15-word sentences, no semicolons. Seeds appear first labeled as such; neighbors below.
- [ ] Catch-up render template's closing block drops the "or survey for the full picture" line. Drill labels (A–E) and the bolded open question remain.
- [ ] When the user's drill phrase doesn't match a labeled cluster (fuzzy-match failure), the agent runs `sdd search --query "<user's phrase>"` as fallback and acknowledges the fallback in one line before rendering results.
- [ ] Fresh-session paste-test evaluation covering: drill into a labeled cluster, drill into an unknown phrase, and drill-then-drill (sequential cluster widening). Closing done signal records voice fidelity (no banned vocabulary), format adherence, expansion quality (right neighbors surfaced, no irrelevant noise), and wall-clock cost.

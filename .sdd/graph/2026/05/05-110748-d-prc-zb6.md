External evaluation captures and any artifacts referencing external projects in this repository must use only generic placeholders for client names, project names, person names, and external-project entry IDs or document structure. Specific identifiers from non-public projects never land in committed content.

Scope: the rule covers external participants and external project material. Names and identity context for actors of this graph itself — captured via `kind: actor` signals — remain in the repo as normal; the actor system exists to carry that information.

Relationship to immutability (d-cpt-e1i): if a redaction-in-place ever proves necessary, replacing only identifying terms qualifies as a mechanical fix because the entry's analytical contribution is preserved. This carve-out doesn't sanction redaction as a normal flow — it only clarifies how immutability handles the rare case where this contract's draft-time discipline failed.

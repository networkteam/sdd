Adopt Mastra (TypeScript) as the agent runtime for the hosted SDD sandbox, connecting to a React UI (assistant-ui or CopilotKit) via AG-UI, and to the Go sdd binary via MCP — with LangGraph (Python) held as the fallback runtime if Mastra proves insufficient. The architecture has three seams: Mastra ↔ AG-UI ↔ React UI; Mastra ↔ MCP ↔ sdd binary; and the choice on either side of each seam can be replaced without forcing the other. The decision rests on TypeScript end-to-end coherence (deployment ergonomics, single-language stack from UI through runtime), Mastra's first-class MCP support via `@mastra/mcp`, and the AG-UI/MCP decoupling that limits the cost of swapping the runtime if needed. LangGraph remains the canonical fallback as the production-mature stateful agent runtime. OpenAI Agents SDK and Claude Agent SDK are deliberately not picked despite technical capability because their vendor association re-raises the lock-in concern the portability gap names. Skill-content portability — the other half of the portability gap — is not addressed by this directive and remains separate work.

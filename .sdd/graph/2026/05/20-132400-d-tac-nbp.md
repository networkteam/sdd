Forward commitment: after Plan-1 (`d-tac-6tz`) ships its capture-time procedure and view infrastructure, design and run the retroactive topic-grooming flow for the existing graph. Completes the topic-backfill half of `s-cpt-sy4` (Plan-1 shipped the `as-counts` half); the directive's done signal closes `s-cpt-sy4` and the grooming half of `s-cpt-ghy`.

Scope:

- **Grooming surface**: a sub-skill (e.g. `/sdd-groom-topics`) or playbook reference that walks the user through retroactive topic assignment — survey untagged or under-connected entries via the `not(topic())` filter and `as-counts` (both from Plan-1), identify candidate clusters, propose labels using the same procedure as capture-time, capture annotation entries on confirm.
- **Backfill exercise**: run the grooming flow on active and open entries in the current graph (closed entries are historical and don't need topics). Produces annotation entries across representative clusters, demonstrating the flow scales and exercises label proposal against the live working set.

Mechanism choice deferred to dialogue after Plan-1 ships. Once we see what `as-counts` and the untagged filter return on the real graph, the grooming flow shapes itself concretely. Sub-skill vs playbook, cluster-identification approach (refs proximity, semantic search, hybrid), and backfill threshold settle then.

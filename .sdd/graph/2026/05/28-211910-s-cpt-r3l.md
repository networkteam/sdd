SDD is in use in this framework repo and being tried in other projects where dialogues sometimes connect across repository boundaries; a planned marketing repo will add another graph to the same working set. The graph has no mechanism for an entry to reference an entry in another repo, so reasoning anchored in another graph either silently re-derives, re-captures locally as paraphrase, or loses the connection. Any meta-view across graphs has no foundation to stand on.

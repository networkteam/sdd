Added `.sdd/index/` to the gitignore set written by `sdd init`, completing the housekeeping list for the per-participant search index. The slice in `internal/handlers/handler_init.go` previously covered `.sdd/tmp/` and `.sdd/config.local.yaml` only, so `sdd init` against a fresh project left the index dir untracked-but-uncommitted (the index is machine-local: keyed by embedder fingerprint, lazy-filled, rebuildable). Updated both `TestInit_FreshProjectEndToEnd` and `TestInit_GitignoreIdempotent` to assert the third entry. Discovered when running the released binary against an external project; this repo's root `.gitignore` had `.sdd/index/` added by hand when the index landed, which masked the omission locally. Fix landed in commit 8c79adf.

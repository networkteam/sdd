Cross-repo references use URL-shaped repository identifiers declared per-repo in `.sdd/config.yaml` and a per-user home-dir mapping from repo ID to local checkout path. Refs live in the standard refs list with `<repo-id>:<entry-id>` inside the JSON id; all eight ref kinds are allowed. Lifecycle effects stay within-repo only — `refines` keeps its label as documentation across the boundary but never derives local status from remote state. References are one-way forward; backlinks and cross-graph search are deferred to a meta-project layer. Participant identity is strictly per-graph for v1; canonical-and-aliases discipline is the human mechanism for keeping the same actor recognizable across repos. See [design](./29-131915-d-cpt-v8t/design.md) for alternatives considered and open questions.

The Engage refactor collapses today's Explore + Act/Implement modes into a single **Engage** mode whose playbook routes to peer post-engage moves, repositions `/sdd-explore` as a goal-tagged research-mission compressor, and fixes the load-order issue from s-prc-kaw. Design rationale and per-kind move matrix in the synthesis insight (s-prc-fc0).

Scope is the immediate skill-prompt rewrite, not the broader lens-flavor moves layer (evaluate, compliance check, alignment check, focus-progress check) which is sequenced separately as a follow-up directive. The Evaluate row gets a temporary fix here (no longer silently mis-points at `playbook-catchup.md`) but its dedicated playbook is out of scope.

Touches `internal/bundledskills/claude/sdd/SKILL.md`, a new `internal/bundledskills/claude/sdd/references/playbook-engage.md`, `internal/bundledskills/claude/sdd-explore/SKILL.md` (rewrite), and removes `playbook-explore.md`. Implementation playbook stays as on-demand reference. Build + reinstall + commit both bundle source and installed `.claude/skills/...` copies per project skill discipline (CLAUDE.md).

## Acceptance criteria

- [ ] Mode table in `internal/bundledskills/claude/sdd/SKILL.md` collapses Explore and Act/Implement into one **Engage** row pointing at `playbook-engage.md`. Bootstrap, Augment-plan, and Groom rows stay. The reference column makes load order explicit (playbook reference loads before any sub-skill invocation).
- [ ] `internal/bundledskills/claude/sdd/references/playbook-engage.md` exists with (a) the four-step universal entry move (anchor → read chain via `sdd show --downstream` → brief → offer moves), (b) the post-engage move catalog keyed by entry kind, (c) the brief-shape family with at least three concrete examples (AC-status table for plan + implementation; narrative for signal + explore; divergence list for contract + compliance-check).
- [ ] `internal/bundledskills/claude/sdd-explore/SKILL.md` rewritten to accept a **target** *and* a **goal** as inputs. The related-entry surfacing uses `sdd search --query` as primary mechanism with `sdd search --term` for known identifiers; the LLM-as-semantic-matcher recipe (bare `sdd list` then read everything) is removed. Output is a goal-tagged compressed brief.
- [ ] `playbook-explore.md` is removed; no orphan reference remains in SKILL.md or any other bundle file.
- [ ] `playbook-implementation.md` stays as on-demand load (loaded when "implement" is chosen post-engage). Mode table no longer lists it as a top-level row.
- [ ] Evaluate row in mode table no longer silently mis-points at `playbook-catchup.md` — temporarily routed at `playbook-engage.md` with an inline note that the dedicated lens-flavor playbook is queued behind, or carries a one-line clarification distinguishing it from catch-up.
- [ ] CLI binary rebuilt (`go build -o bin/sdd ./cmd/sdd`) and skills reinstalled (`./bin/sdd init --scope project`); both bundle source and the matching `.claude/skills/...` installed copies are committed together.
- [ ] Closing done signal closes this plan and the originating gap `s-prc-kaw`, recording: the new playbook(s) shipped, the sub-skill rewrite shape, the mode-table changes, and any deviations.

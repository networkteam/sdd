Session dialogue identified a semantic mismatch in s-cpt-8tu's proposal: planning entries are described as `kind: activity` but their lifecycle is supersession-based, not done-signal closure. Activity semantics require completion via done signal; planning entries are superseded when priorities change, not closed when work is done.

This synthesis proposes resolving the tension with a new decision kind (provisionally "focus") carrying dual lifecycle semantics — supersedable when priorities shift, completable via done signal when a cycle ends naturally — with involvement triples in frontmatter. This is a design proposal; realising it requires a conceptual decision superseding d-cpt-ygn (the 6+6 type system contract). See [design dialogue](./05-215453-s-cpt-ke6/focus-decision-design.md).

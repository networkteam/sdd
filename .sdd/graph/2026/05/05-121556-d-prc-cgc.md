Refines the bootstrap plan by swapping Move 3 (actor capture) and Move 4 (Golden Circle strategic seeding) in `sdd-bootstrap/SKILL.md`: Golden Circle runs first so participants self-describe with project framing already grounded.

Participant attribution during Move 4 relies on the local canonical from `.sdd/config.local.yaml` (set by `sdd init` before bootstrap runs); grace mode covers the gap until the actor signal lands in the later Move 3. To handle the case where the user wants a different canonical than config has, orientation includes a one-line confirmation ("is `<config-canonical>` the right name, or want a different one?") *before* any capture, with the chosen value flowing into `--participants`. Multi-participant attribution remains scoped to Move 3's downstream sweep — entries captured before then carry the local participant only, matching bootstrap's design (team members enter the graph as the local user grows it).

Updated paths: brownfield = readiness sweep → context gather → Golden Circle → actor capture → handoff; greenfield = readiness sweep → Golden Circle → actor capture → handoff.

`sdd stats` styling predates and diverges from the CLI color-scheme directive (d-cpt-n0f). Stats ships its own palette — bold headers, dim color 8, cyan-6 column heads — set when `sdd stats` v1 landed (s-tac-4wp), before the color scheme was worked out and standardized during the `sdd show` restructure. The directive establishes a single scheme for styled CLI output: ids gold, kind and live-status white-bold, ref kinds purple, secondary text in glamour's body grey, structure faint. Stats should be brought into line with it as the command is next touched, so styled output reads consistently across the CLI.

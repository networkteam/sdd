Surfaced per-call LLM usage on the gollm/anthropic path and made it collectable. In the gollm fork (branch generate-with-usage, commit 7aec6bb, pushed to networkteam/gollm), added GenerateWithUsage returning the full Response with a Usage carrying the Anthropic input/output plus prompt-cache read/creation breakdown (OpenAI prompt/completion fallback). In sdd (commit 21b6830), the adapter maps that into LLMMetadata with the configured provider, and a default-on JSONL sink appends one record per call to .sdd/stats/llm.jsonl (op, provider, model, tokens, cache read/creation, duration), hooked at logCallResult and wired through the command context. Verified end-to-end: two identical pre-flight calls recorded a cache_creation then a 6163-token cache_read. Cost is deliberately excluded — the provider APIs report tokens, not a dollar cost, and no pricing table is maintained. Closes the observability gap (s-tac-sae) and the directive (d-tac-zis).

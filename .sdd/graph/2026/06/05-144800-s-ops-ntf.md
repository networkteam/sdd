The release workflow's `actions/attest-build-provenance@v1` step runs on the deprecated Node.js 20 runtime. GitHub forces these actions to Node 24 starting 2026-06-16 and removes Node 20 from runners on 2026-09-16. The v0.7.1 release succeeded with only a deprecation annotation (no failure), but the step is now inside the force-migration window. This deprecation was first flagged as a non-blocking future item when the v0.1.0 release pipeline shipped (s-tac-r8l); it has gone unaddressed since. The remedy is a straightforward bump to `actions/attest-build-provenance@v4` (latest v4.1.0), which is now a composite action delegating to Node 24 sub-actions, clearing the warning without changing the attestation behaviour.

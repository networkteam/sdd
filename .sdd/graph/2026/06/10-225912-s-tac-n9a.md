Slice 1 of the workflow MCP server shipped in commit f92fed5, closing the build activity (20260610-224323-d-tac-et4). `sdd serve` hosts a per-session state machine inside the sdd binary with the four dialogue-loop tools — open-session, ground, capture, show-entry — each returning graph data plus just-in-time instructions; the grounding gate is enforced structurally (capture refuses to run before a ground call happened in the session), and pre-flight findings flow back structurally through a new OnPreflight callback on the entry-creation command, so a blocked capture returns findings plus revision instructions instead of a CLI error. Both transports are live: stdio and streamable HTTP with a mandatory bearer token (--auth-token flag or SDD_SERVE_TOKEN env).

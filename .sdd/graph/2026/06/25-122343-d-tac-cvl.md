Build the catch-up open-loops lane: a new `coldness` rank algorithm in `sdd view` plus a second catch-up data lane that surfaces unacted-on commitments, resolving the carrying-question blind spot. Catch-up's heat ranking answers only "what is the project converging on" and is structurally blind to "what have I committed to but not yet acted on" — an unacted entry has no incoming refs, scores ~0, and falls off the result cap. This plan realizes the inverse-heat model from the insight (20260625-115201-s-cpt-6h6): coldness(e) = decay(entry-age) / (1 + in-degree(e)), reusing the existing decay vocabulary applied to the entry's own age, with each incoming ref gradually demoting an entry toward the hot lane and slow age-decay (exp-30d) letting ancient orphans fade. It addresses both dimensions of the gap (20260625-115123-s-prc-6cw): dimension two (fresh plans/activities dropped by cold-start heat) directly, and dimension one (fresh directives, currently in no lane) by including the directive kind. The lane shows everyone's open loops (kind plan, activity, directive, gap, question), carries each entry's upstream via expand(refs) so the briefing agent can weave it into the story-arc thread its upstream belongs to — a genuinely disconnected entry becomes a new-direction beat — and is not rendered as a flat block. Excluding intent: guiding directives is deferred until the directive-intent attribute (20260610-000354-d-tac-n9k) ships, a coordination coupling recorded in the spec. Full design, decisions, and test cases in the attached spec (./25-122343-d-tac-cvl/spec.md).

## Acceptance criteria

- [ ] A `coldness` rank algorithm computes `decay(entry-age) / (1 + in-degree)`: `rank(coldness)` and `rank(coldness(<decay>))` parse, scores match the formula (fresh-unacted ranks highest, each incoming ref demotes, entry age fades the score), an unknown decay errors, and bare `rank(coldness)` defaults to `exp-30d` (not the global `exp-14d`)
- [ ] The catch-up template gains an "Open loops" lane — `kind(plan,activity,directive,gap,question):active:rank(coldness(exp-30d)):n(8):expand(refs):name("Open loops"):as-list` — rendering correctly in both the Claude injection form and the Codex instruction form
- [ ] The catch-up sub-skill instructs the agent to weave open-loop entries into the existing story-arc threads via their upstream refs (marked as unattended), treat a disconnected open-loop entry as its own new-direction beat, and not render a standalone "Open loops" section
- [ ] `coldness` is documented in both rank-vocabulary surfaces: the `sdd view` help text and the `cli-reference` skill-doc algorithms table
- [ ] Installed skill renders are refreshed and committed via `sdd init`, and the Codex render still validates (`devbox run validate-skills`); `go vet`, `go test`, and `golangci-lint` pass clean
- [ ] The starting `exp-30d` half-life is sanity-checked against the live graph at closure — confirming it surfaces genuinely unacted commitments without flooding or over-fading — with findings recorded and the default revised if warranted

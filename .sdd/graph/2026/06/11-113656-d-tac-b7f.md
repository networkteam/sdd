Enforce body-to-edge ID consistency in pre-flight using the division of labor the applicability matrix established: mechanical detection, LLM verdict. Code extracts every entry ID typed in the body and diffs it against refs ∪ closes ∪ supersedes, reporting each dangling mention as a fact line in the validator's user prompt; the validator judges whether the narrative depends on the mentioned entry (missing ref — medium, with the body quote as anchor) or whether it is a hypothetical example or quoted excerpt (no finding). The inverse direction — a ref the body never mentions or supports — is likewise mechanically detected and feeds the existing unrelated-refs judgment. No mechanical severity is assigned: a live-graph scan found 6 of 31 ID-carrying entries with dangling mentions, one of them a hypothetical example ID in prose, so a deterministic block would misfire on legitimate authoring — detection is deterministic, the verdict stays semantic. This closes the prose-refs divergence gap (s-cpt-7ix): its proposed rule entered skill guidance via the ref-capture refinement (s-prc-ema), and this directive supplies the missing enforcement half. Ships with its own eval delta per the regression discipline (s-tac-lpa): pinned cases for a genuine missed ref, a hypothetical-example body, and an unmentioned structural ref.

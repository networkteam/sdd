Go text/template, with its default double-brace delimiters, is SDD's standard mechanism for generating text, replacing hand-rolled string-building across the codebase. Default delimiters are kept — the lone collision, the attachments-path placeholder, is escaped in template source and caught loudly by the parity smoke test. Templates become the default wherever code does excessive hand-rolled string-building to generate text, migrated incrementally as touched; interactive TTY rendering and structure-preserving YAML edits are deliberately excluded. This is a standing engineering standard for new text-generation code — hence guiding.

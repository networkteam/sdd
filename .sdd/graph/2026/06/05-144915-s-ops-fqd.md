Bumped the release workflow's `actions/attest-build-provenance` step from `@v1` to `@v4` (commit e881f92) to clear the Node.js 20 deprecation flagged on the v0.7.1 release run. v4.1.0 is a composite action that delegates to Node 24 sub-actions, so the change clears the forced-migration warning (Node 24 forced 2026-06-16, Node 20 removed 2026-09-16) without altering attestation behaviour — the attested subjects (`dist/*.tar.gz`, `dist/*_checksums.txt`, `install.sh`) and permissions are unchanged. The workflow only executes on tag push, so the warning's disappearance is confirmable on the next tagged release rather than now; the config change itself is complete and committed.

Establishes a universal capture-time invariant: every reference must resolve, or capture is blocked with a high-severity precondition finding — one rule for local and cross-repo refs alike. Today a dangling local ref is only a `sdd lint` warning, not a capture block; this directive promotes it to a blocking pre-flight precondition. The rule follows from immutability (d-cpt-e1i): references point backward at entries that already exist, so a local ref that does not resolve is a typo or a broken edge, never a state worth persisting. Cross-repo references inherit the same invariant — they resolve against the connected-repo cache, and on a cache miss the capture path fetches fresh before deciding, blocking only if the target is genuinely absent from the other repo's default branch (no silent fallback). The forward-class ref kinds (surfaces, required-by) are unaffected, since they still point at an entry captured first. The enforcement mechanism — mechanical pre-flight gaining a resolution precondition over every ref id — is left to the implementing plans; this directive sets the invariant they enforce.

Shipped the generalized artifact-durability rubric committed to in d-prc-kqx. Pre-flight's durability check now recognizes any of several durable artifacts for a done signal — a commit, an attachment on the entry or a referenced upstream entry, a URL to external work (PR/CI/deploy), or, for an act that changed nothing, a human participant's attestation — with "most specific" as author guidance. The one hard requirement is scoped to changes to the repository's code or source: those must cite the commit that landed them (high); a done whose deliverable is an attached document (research/synthesis/evaluation) is durable via that attachment and is not blocked. Landed in commit 2e3c6bc: durability.tmpl rewritten, the code-change eval fixtures updated to cite commits, and three new eval cases added for the attestation, external-URL, and attachment-as-deliverable paths. An initial cut over-scoped the hard line to any in-repo file change, which would have false-blocked attachment-backed knowledge work; that was caught in review and narrowed before merge. Validated by the live pre-flight eval (durability subset, 10/10 pass): attestation, external-URL, and research-attachment dones are accepted with no durability finding, while code/source changes without a commit correctly block high. vet, the non-eval suite, lint, and build are clean. This closes d-prc-kqx; the evaluation marker, sibling-relation, and finding-kind facets of the evaluation-capture gap remain open under the evaluate-move work.

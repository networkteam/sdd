Pre-flight's LLM ref-meta advisory blocks valid entries non-deterministically: on a genuinely borderline ref shape, repeated runs over equivalent input returned contradictory `[high]` verdicts and unstable severities, so neither the recommended kind nor the block/pass line is reproducible. The airtight case (external user, v0.7.0): a ref pointing at a **terminal `done` signal whose body flagged a follow-up**, a shape framework-concepts gives no tie-break for — `builds-on`, `addresses`, and `grounded-in` are all defensible. With body and ref `desc` held identical, `builds-on` was blocked at `[high]` recommending `addresses` while `addresses` was blocked at `[high]` recommending `builds-on` — each run rejecting the kind the prior run demanded; a later `desc` reword passed the same `builds-on` at `[low]`. The mechanical checks (closed-set kind, dangling refs, canonical participants, AC presence, language) stayed deterministic — only the semantic judgment oscillated. This escalates the ref-kind over-eagerness gap (s-tac-4h7) from debatable mediums to contradictory high-severity blocks, and is a fresh external instance of the oscillation-and-bypass pattern (s-prc-vvd). It persists *after* the medium→low recalibration (d-prc-2is) and the derived-status input, because those touched the medium tier and status-awareness, not high-severity judgment variance on borderline shapes. Three directions are open and not yet decided: cap the semantic advisory below `[high]` so only deterministic mechanical checks gate creation; pin determinism (temperature 0 / N-run agreement before raising `[high]`); or add a spec tie-break for the terminal-`done`-with-flagged-follow-up shape. A contributing factor is unconfirmed — the reporter had switched pre-flight from Haiku 4.5 to Sonnet 4.6, but the pattern predates that (Haiku-era in s-prc-vvd), so model choice at most changes the variance's character, not its existence.

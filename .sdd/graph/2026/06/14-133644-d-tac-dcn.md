Decide the agent runtime for a hosted SDD webapp aimed at non-technical people (the non-developer-access aspiration, 20260422-122523-d-stg-x0l) by running two throw-away comparative spikes — one on Mastra (TypeScript), one on agent-sdk-go (Go) — and scoring them against a shared rubric, rather than committing a runtime on a feature-list read. The question this resolves: does staying in one Go stack (agent in-process with the existing finders and handlers, no MCP bridge) outweigh Mastra's more mature UI story (AG-UI + assistant-ui / CopilotKit) — a genuine trade-off, not a UI-time race. This revisits the May runtime research (20260525-204809-s-tac-zsr), which concluded no viable Go-native runtime existed and parked Go at the graph layer; agent-sdk-go — Go-native and multi-provider — is the data point that reopens it. Each spike is built in its own worktree and neither merges. The single-source rule (20260614-110729-d-cpt-chi) is a scored dimension: each spike must render its process instructions from the one neutral template source, not a hand-ported copy. The verdict feeds the held runtime/architecture direction and confirms or supersedes the Mastra directive (20260525-204836-d-cpt-t3j). Full rubric in [the attached evaluation rubric](./14-133644-d-tac-dcn/evaluation-rubric.md).

## Acceptance criteria

- [ ] Both spikes reach the shared bar — a web UI where a non-technical user gets a plain-language catch-up and captures one new entry through guided dialogue with confirmation, end to end against a real sdd repo — so the comparison is apples-to-apples.
- [ ] Each runtime is scored on all six dimensions with concrete evidence: UI effort and quality, SDD-loop fidelity, single-source instruction rendering, stack and operational cost, graph-integration cleanliness, and maturity/ownership.
- [ ] UI effort and the single-Go-stack benefit are weighed against each other explicitly — neither dimension decides alone.
- [ ] A written per-dimension comparison records pros and cons for both runtimes.
- [ ] A runtime recommendation is captured that confirms or supersedes the Mastra directive (20260525-204836-d-cpt-t3j) and unblocks the held runtime/architecture direction.

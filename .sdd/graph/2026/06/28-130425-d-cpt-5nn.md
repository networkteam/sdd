If done signals are ever given derived topics, derive them from the `closes` edge only — binary membership from the single edge where the done unambiguously retired its target, so the target's topic transfers without guessing. Deliberately excluded: `addresses` and broader completion kinds, and any weighted per-ref-kind transfer (weights only make membership fractional, incompatible with the topic filter, as-counts, and rendering). Scalar "how central" gradation stays the domain of heat weighting; topics stay binary membership. This is a standing constraint on a hypothetical future derivation — no action is demanded now, but it shapes that decision if taken — hence guiding.

Pre-flight's ref-meta advisory never blocks on ambiguity: a ref-kind whose precondition holds for the target is applicable, so the strongest finding it may draw is [low] ref-kind-sharpness; [high] ref-kind-mismatch is reserved for kinds whose precondition is actually violated (refines on a closed target, depends-on pointing backwards). High severity must mean the kind is wrong, not that a sharper kind might exist — when several kinds are each applicable there is no error to block on. It also pins the recommendation: for a terminal done with a flagged follow-up, the canonical kind is builds-on (the next step after a finished chain) or grounded-in (when the body reasons from the done as evidence), never addresses. This is a standing calibration of the high-severity boundary — hence guiding. Promoted to a standalone directive because its predecessor refined a since-superseded calibration directive, so the refinement was rebased per the fold-in/promote rule; it sits alongside the live ref-kind sharpness calibration (d-prc-asz) as the high-severity-tier sibling.

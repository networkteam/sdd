A current sdd binary must be able to read every older graph entry it encounters; read-compatibility with prior on-disk formats is permanent and never silently dropped. Entries are immutable (d-cpt-e1i), so their stored form is a fixed historical fact — the tooling that reads them must preserve the ability to read every format version that has ever existed. A change that would break readability must ship with a conversion path that restores it; it may never leave older entries unreadable. This is a universal constraint on the tooling↔graph relationship, independent of how any binary is obtained — built from source or installed as a released CLI.

Narrowed the supersede-fork lint to live forks only, closing d-cpt-rgx (commit 2669514). `validateSupersedeForks` now resolves each branch of a forked entry to its head and warns only when more than one head is still active (not closed); settled forks — branches all closed or reconverged to a single head — stay quiet. Verified on the live graph: the previously-flagged benign fork (a question whose two successors have both since closed) is now silent, while a genuine fork with competing active heads still warns. The full vet/test/lint gate is clean (golangci 0 issues), and tests cover the live, settled, converged-diamond, and linear cases. This implements the directive's bounded commitment — the lint scope; the converge-forward resolution method and capture-time prevention it also records are documented practice, not separate code deliverables.

Commit to a deliberate, consistent output policy across the sdd CLI and tooling: human readers get readable, decorated output; agents and machines get clean, decoration-free, structured output. sdd show renders as a YAML frontmatter envelope plus raw markdown body (mirroring on-disk storage); programmatic callers get JSON via --format json / MCP structuredContent; operational logging goes to stderr and results to stdout; decoration is TTY-detected and honors NO_COLOR; standard formats are preferred over bespoke rendering everywhere. This is a standing policy constraining every command's output surface — hence guiding.

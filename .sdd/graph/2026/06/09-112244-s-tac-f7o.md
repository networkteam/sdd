`sdd show --format json` has no owning plan. The output policy (d-cpt-rkj) commits programmatic callers to JSON via `--format json` and MCP `structuredContent`, and the `sdd show` restructure (d-tac-z3k) deferred its own `--format json` explicitly so the schema would be defined once alongside that structuredContent. But the MCP server plan (d-tac-0v4) renders read tools — `show` included — as presenter-text with byte-for-byte CLI parity, returning no structured JSON for reads. So the JSON read surface the policy designates, and that z3k deferred to 0v4, sits in neither plan's scope and needs an owner before it can ship.

Built and evaluated the Mastra (TypeScript) runtime spike: a throw-away hosted SDD agent wiring the sdd CLI as 1:1 shell-executed tools (one per subcommand — view/search/show/list/new/summarize/info, no MCP server), rendering its system prompt from the single bundledskills template source via a new `mastra` render profile, fronted by Mastra Studio plus a custom streaming web chat. It reached the shared evaluation bar live — a plain-language catch-up and a dialogue-before-capture run through the real pre-flight gate against the real graph, including hands-on by Christopher. Key finding: wiring the CLI as shell-executed tools works, so the CLI-parity MCP Layer-1 server (20260527-210616-d-tac-0v4) is not a prerequisite for a hosted agent, narrowing the design space. Per-dimension findings are in the attached evaluation: strengths are UI maturity (a clean chat is cheap) and high SDD-loop fidelity (widen, dialogue-gated capture, pre-flight honored, summary verified); the real cost is a second Node stack plus an out-of-process bridge; the token-heavy instruction prompt is a shared hosted-approach cost — both spikes load the same instructions — now mitigated by Anthropic prompt caching. Spike code stays on the worktree-f09 branch (not merged); this signal and the attached findings are the record on main. Feeds the runtime verdict (20260614-133644-d-tac-dcn) without deciding it — the head-to-head comparison against the Go spike is separate.

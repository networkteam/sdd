Thread the gollm fork's per-call usage (input/output tokens, cost, cache_read/cache_creation counts) into the existing agent-neutral LLMMetadata so the gollm/anthropic path stops returning Meta nil, and collect it to a local stats sink — e.g. an append-only JSON file under .sdd/ keyed by operation (preflight, summarize) — so prompt-cache effectiveness and per-operation cost become measurable over time. Extends the metadata abstraction built for the claude-cli path (d-tac-gyk) to the now-active gollm provider, closing the observability gap on that path (s-tac-sae). The sink format and exact location are a candidate mechanism, settled in implementation; gating choices include what to persist per call and whether the sink is on by default or behind a verbosity/config flag.

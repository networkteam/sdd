Re-scope the CLI-parity MCP server to an optional, deferred capability for non-Go external agents. The Go runtime verdict (d-cpt-8k5) makes an in-process Go agent the hosted-runtime path, which needs no MCP bridge — so this server's original premise, being the foundation for a Mastra-based hosted-agent PoC, no longer holds. It keeps conditional value only for a non-Go external agent (for example a hosted ChatGPT) that cannot run the Go core in-process and needs structured graph access over MCP. Deferred: not built now, built only if such a need actually arises. Supersedes d-tac-0v4 to correct its premise and priority — the technical design and implementation criteria in the superseded plan still stand as the spec.

## Acceptance criteria

- [ ] Deferred until a non-Go external agent that cannot integrate the Go core in-process is actually targeted; only then is the MCP server implemented against the preserved spec (CLI-parity tools over stdio + streamable HTTP, in-memory graph behind GraphFileSyncer, pluggable AttachmentStore).

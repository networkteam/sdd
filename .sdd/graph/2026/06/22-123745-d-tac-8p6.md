Waive `--missing-kind` parity for the `sdd list` retirement (20260622-095321-d-tac-8u5): the flag will not be ported to `sdd view`. It is a one-off migration helper that surfaces entries lacking an explicit `kind` field, and a full-graph sweep (including closed and superseded entries) now finds zero such entries — kinds are completely backfilled — so the helper has no remaining purpose. With the `type()` filter already shipped, this resolves the second of the two `sdd view` parity gates the retirement directive named, leaving `sdd list` removal unblocked on parity grounds and gated now only on the migration work itself.

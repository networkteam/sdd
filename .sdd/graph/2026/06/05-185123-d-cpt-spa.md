Augments the cross-repo reference design (d-cpt-v8t) after deeper planning, refining it in place rather than replacing it. Three revisions. First, cross-graph discovery is brought into scope: the original directive deferred cross-graph search to a future meta-project layer, but a reference you cannot discover or read across repos is not usable, so search across connected repos is now in scope — only who-cites-me backlinks stay deferred. Second, sdd-managed repo caches plus a global connected-repos registry replace the directive's user-maintained checkout mapping — an explicit reversal: rather than the user wiring repo-id to a local path, sdd clones each connected repo (by a registered clone URL, kept distinct from the canonical repo-id) into a homedir cache it owns and pulls lazily. Third, a single global embedder indexes every connected repo, so cross-graph search fuses per-repo indexes by comparable cosine score into one ranked list; the local repo keeps its own in-repo index, the cache holds the others. Cross-repo references resolve-or-block at capture per the universal invariant (d-cpt-ba7): on a cache miss the capture path fetches fresh and blocks only if the target is genuinely absent from the other repo's default branch. `sdd show` follows cross-repo chains fully, bounded by max-depth with (repo-id, entry-id) dedup, and refs render with the full canonical repo-id prefix and no remote status segment — status never crosses the boundary, preserving the original directive's within-repo-lifecycle commitment. Implementation, command surface, and acceptance criteria are deferred to the cross-repo plan.

SDD runs on multiple agent harnesses by generalizing its skill and instruction source into agent-neutral templates rendered per agent, with Claude Code one render target among several (Codex shipped; others anticipated). It is a thin port — skills plus a shell-invoked sdd CLI — with one template source dual-rendered to distinct per-agent dirs via template conditionals (never duplicated definitions), a committed supported_agents list in config, and a canonical AGENTS.md bridging instructions. This is a standing multi-agent commitment that shapes every new harness target — hence guiding.

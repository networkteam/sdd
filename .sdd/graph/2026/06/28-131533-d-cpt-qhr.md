Sharpen the output policy's audience-to-format mapping into three distinct renderings rather than two: human readers in a TTY get genuinely styled output (lipgloss layout, color, framing), agents and other non-TTY readers get the YAML frontmatter plus markdown body, and programmatic callers get JSON via --format json / MCP structuredContent. Renderer is selected by TTY detection plus --format (precedence flags > env > config > defaults), implemented as a presenter layer holding one entry-data model with three renderers on the existing CQRS split. This is a standing refinement of the output policy every human-facing surface conforms to — hence guiding.

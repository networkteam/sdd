Build a `/sdd-groom-topics` sub-skill that surveys the topic landscape, flags drift and consistency issues, and walks topic grooming — with current graph state injected dynamically at invocation, mirroring `/sdd-catchup`. Grew out of the first manual topic backfill (this session), which proved the flow but showed it deserves a real, reusable surface rather than ad-hoc inline runs.

## Acceptance criteria

- [ ] A `/sdd-groom-topics` sub-skill exists (source in `internal/bundledskills/claude/`, rebuilt and reinstalled via `sdd init`), invoked via the Skill tool.
- [ ] At invocation it dynamically injects current graph state — topic counts (`active:as-counts`) and the untagged active non-done set — following the `/sdd-catchup` injection pattern.
- [ ] It surveys the full topic landscape for drift and consistency issues (divergent or overlapping labels, singletons, stranded labels), not only untagged entries, and surfaces them for the user.
- [ ] It walks the proven backfill flow for untagged entries: survey → cluster into nested families → iterate with the user → capture one annotation per family via `--topic '{label, members}'`.
- [ ] `/sdd` SKILL.md gains mode/trigger guidance for when to invoke `/sdd-groom-topics`.
- [ ] Topic reorganization: the sub-skill drives renaming and merging of existing labels via a topic rename/merge command (assumed: a new `sdd` topic command). Depends on s-cpt-k1b — this AC is met only once that gap resolves into the rename/merge mechanism.

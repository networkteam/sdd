Perspectival memory — a per-participant view of the graph — can be a *derived read-layer*, computed on read like status, topics, or the role-status cascade, never a stored parallel record. This is the SDD-shaped answer to Honcho's stored (observer, observed) representations: where Honcho persists inferred conclusions about each peer, SDD would derive the equivalent view from entries it already holds, so it stays inside "the graph is the sole record" (d-stg-3k0) and can't drift — unlike the one derivation we do persist, summaries, which does (s-cpt-tdp).

Scope is what keeps it honest. Over a *reasoning* graph, a per-actor projection yields a **commitment/engagement footprint** — what an actor decided, questioned, grounded in, which topics they touch — not a personality model. We infer "what has X reasoned," never "what is X like." That inversion of Honcho's theory-of-mind is precisely what holds the line against implicit learning (dialogue-first, d-stg-beb): the projection reads committed reasoning, it doesn't infer traits from raw dialogue.

The first concrete instance is **per-participant catch-up** — surfacing what moved in the areas a participant has engaged and where they'd re-enter at the edge of their own thinking, rather than a one-size briefing. This directly serves cross-participant coherence (d-stg-qlt) and gets real now that Christopher, Claude, and Jonathan touch different parts of the graph. It also plugs into the workflow agent's guide role (r57), which reads the graph directly.

Open: whether SDD ever wants genuinely observer-relative state — what X believes about Y, Honcho's full (observer, observed) keying — versus strictly single-truth derivations. The footprint view above is single-truth (derived from one shared graph); cross-peer belief modeling is a separate, unanswered question.

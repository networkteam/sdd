Adopt Go `text/template` (default `{{ }}` delimiters) as SDD's mechanism for generating text, replacing the hand-rolled string-building that has accreted across the codebase. Immediate application: the agent-neutral skill render and the `AGENTS.md` / `CLAUDE.md` bridge in the multi-agent plan (d-tac-4ln) — a single template pass with `{{ template }}` includes, `{{ if eq .Agent … }}` conditionals, and helpers (`inject` for Claude's `!`cmd`` vs Codex's "run `sdd …`" instruction; `stamp` for the per-profile frontmatter shape) replaces `ResolveSkillIncludes`, `RenderSkillFile`, and the per-agent comment-conditional parser that would otherwise be added — realizing the plan's ACs 1 and 5 as a net deletion of bespoke code.

Default delimiters are kept over a custom pair because they are idiomatic Go and the only collision is the documented attachments-path placeholder that `sdd new` resolves into entry descriptions — a token the skill docs explain and must emit verbatim. It is escaped in template source (see the design note); a forgotten escape fails template parse, so the parity smoke test (d-tac-4ln AC 2) catches it loudly rather than letting it corrupt output. Rejected: hand-rolling comment-directive conditionals (adds more of the bespoke parser code this directive aims to remove); and a profile-overlay model (duplicates whole bodies to swap a single inline sentence, violating the no-duplication commitment).

Beyond this plan, templates become the default wherever the current code does excessive hand-rolled string building to *generate* text — fresh-file writers (config and `.gitignore` creation), pre-flight prompt assembly, file-generating presenters — migrated incrementally as touched. Two classes are deliberately excluded: interactive TTY rendering (`sdd status`/`view`/`show` through glamour and color), and structure-preserving edits such as the comment- and key-preserving YAML round-trip (`SetYAMLField` over a `yaml.Node` tree), where a template would clobber content it must retain.

See the [design note](./11-162553-d-tac-dtl/go-templates-render.md) for the deviation catalog, escape handling, code mapping, and open questions.

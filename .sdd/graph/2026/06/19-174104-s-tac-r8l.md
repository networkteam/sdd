Added a `participant()` filter and a `group(by(participant))` field to the `sdd view` pipeline, shipped in commit 5e42e4d. The filter mirrors the existing `kind()` pattern — names disjoin within a single call and intersect across calls — and matches each entry's canonical participants exactly, consistent with the canonical-only participants contract. group-by participant is multi-valued: a co-authored entry buckets under each author, so per-bucket counts can exceed the entry total and an entry with no participants contributes to no bucket. Verified against the live graph (single and quoted multi-word names, disjunction versus intersection, and grouped output) with new unit tests plus vet and lint clean. This closes the participant-filter gap (s-tac-wmn): answering "what did participant X capture" no longer requires grepping entry frontmatter.

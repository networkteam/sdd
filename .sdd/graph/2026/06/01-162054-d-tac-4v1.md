Fork gollm and add provider-aware retry to SDD's LLM layer, implementing the fork directive (d-cpt-n3y) and closing the no-retry deficiency (s-tac-m1b). The fork (`networkteam/gollm`, same module path) gains a retry policy in gollm's HTTP/Generate path that classifies errors as retryable-transient, rate-limited-with-server-delay, or permanent; honors Anthropic `retry-after` and OpenAI `retry-after-ms`; uses exponential backoff with jitter otherwise; never retries permanent errors or `insufficient_quota`; and logs quietly so batch summarize doesn't flood. SDD wires it in via require+replace and exposes bounded, configurable retry knobs. See [design](./01-162054-d-tac-4v1/plan.md) for the per-provider rate-limit reference, code touch points, alternatives considered, testing strategy, and open questions.

## Acceptance criteria

- [ ] Fork `networkteam/gollm` (same module path) plus `require`/`replace` in sdd's go.mod resolves in both local `go build` and goreleaser builds, with `github.com/teilomillet/gollm` import paths unchanged.
- [ ] Transient failures retry: connection/network errors, HTTP 408, 409, and 5xx (including Anthropic 529); the `connection reset` that motivated this no longer fails a single call.
- [ ] Server-provided wait is honored: a 429 with Anthropic `retry-after` (seconds) or OpenAI `retry-after-ms` (milliseconds) waits at least that duration before retrying; absent a header, exponential backoff with jitter applies.
- [ ] Permanent errors are never retried: 4xx other than rate-limit 429s, and OpenAI `insufficient_quota`, fail immediately without consuming retry attempts.
- [ ] Retries are bounded and configurable: a default max-attempts and base/max backoff apply, overridable via `.sdd/config.local.yaml`; reaching the cap returns the underlying error.
- [ ] Quiet logging: per-attempt retries log at debug, not warn, so `sdd summarize --all` over many entries does not flood; the policy applies on both the `sdd new` pre-flight path and `sdd summarize`.
- [ ] Error classification and delay computation are unit-tested: header parsing (including OpenAI `reset-*` duration strings), retryable-vs-permanent classification (including `insufficient_quota`), backoff growth, and jitter bounds.
- [ ] A PR is opened upstream to `teilomillet/gollm`, and the `replace` directive is documented as removable once it lands.

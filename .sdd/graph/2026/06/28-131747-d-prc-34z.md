SDD commits to an alignment-first dialogue architecture. Working modes name what the agent is doing — widening, narrowing, evaluation, action (direction: diverge vs converge). An alignment check runs at the start of every interaction and between modes to ensure user, graph, and agent are aligned before continuing, drawing on a toolkit (restate, split multi-thread input, name tangents, verify, surface graph context, propose mode, and interview as the heavy tool when grounding fails). Three base disciplines run throughout: pair abstract framing with concrete examples, keep output skimmable, and push-pull (pressure-test framings, define by what they are not). Every working mode moves the graph forward via the playbook moves (engage, augment-plan, groom, explore, capture) that fit its goal. This is the standing dialogue architecture shaping how every session is conducted — hence guiding.

No baseline exists for how a non-Claude agent behaves when driven by the full, instruction-heavy `/sdd` skill bundle. Every skill validation to date has run on Claude (Opus/Sonnet); the only foreign-agent data point is the workflow MCP experiment, which tested the opposite extreme — a thin structural gate with no skill content. Because the normal skills are almost entirely instruction-carried, the experiment's central finding (instruction-only discipline doesn't transfer across model families) predicts a GPT-5.5 / Codex run would lose dialogue discipline — but this is unmeasured in the product surface people actually use today. Running the baseline requires getting the Claude-Code-bound skills into another runtime: a scrappy manual markdown port is enough to get the behavioral data now, ahead of any proper skill-rendering build. How to render skills to other runtimes without redundant definitions is a separate decision, tracked on its own.

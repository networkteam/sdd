The experiment's central pattern: structural enforcement transfers across model families, instruction-carried discipline does not. One client held playback discipline on instruction text alone; the other received the identical instruction in the tool result immediately preceding each violation and captured unconfirmed text anyway — an executor posture where every judgment self-serves inside the turn and nothing returns to dialogue unless a tool refuses. The failures were dialogue-discipline failures, not intelligence gaps, which argues the specialist needs a richer state machine, not server-side agent reasoning. Candidate design, an enforcement ladder of five rungs: static instructions (held for one client); re-emitted instructions (effectively already tested — present and ignored); situational challenge responses, where the state machine detects suspicious call patterns (ground followed immediately by capture, a blocked capture instantly re-captured) and answers with a challenge instead of a result; a propose-then-capture handshake that forces a proposal artifact but remains climbable by a determined executor; and elicitation-routed confirmation, where the user confirms the exact entry text through the client UI outside the agent's control — the only rung an executor cannot bypass, requiring per-client feature detection with the handshake as fallback. Smaller iterations ride along: participant-inference instructions and read-only tool annotations. This synthesis extends the closed experiment (20260609-234656-d-cpt-afn) and is the substrate for the slice-2 decision.

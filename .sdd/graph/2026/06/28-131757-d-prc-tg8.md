The alignment-first dialogue architecture ships as procedural text — concrete steps tied to specific moments — rather than as principles the agent interprets. Each alignment moment (conversation entry, mode transition, capture-time grounding, drift-recovery) gets named operations the agent executes, not rules to apply by judgment, on the hypothesis that procedural shape removes the interpretation latitude principle shape leaves open. This binds the architecture's follow-up implementation, which should fold in the capture-time grounding commitment as one of the procedural moments rather than ship it separately. This is a standing constraint on how the alignment architecture is realized — hence guiding.

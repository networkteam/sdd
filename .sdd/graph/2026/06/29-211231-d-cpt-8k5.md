Adopt the Go agent runtime (agent-sdk-go) for SDD's hosted-agent runtime, superseding the Mastra (TypeScript) direction. This is the verdict the comparative spike plan (d-tac-dcn) was built to produce: both throw-away spikes cleared the shared bar (Go: s-tac-f6k; Mastra: s-tac-i6m), so it is not a capability gap but a stack choice — and Go wins on the dimension that compounds. The entire SDD core is already Go, so an in-process agent calls the existing finders and handlers directly with zero CLI/agent drift, versus Mastra's second Node stack and out-of-process bridge. Mastra's one real edge was UI maturity, and the Go spike showed the assistant-ui/CopilotKit UI is reachable by owning one AG-UI adapter plus the vendorable community Go AG-UI SDK; the accepted cost is a heavy transitive dependency tree and a pre-1.0 agent-sdk-go with rough edges. The runtime is not LLM-free, but its LLM use stays in three clean roles, all served by Go: deterministic rails (mode state, goal sequencing, the mechanical gate); a separate in-loop validator LLM (pre-flight judgment, semantic rule discovery — already in the Go llm package, in-process, honoring the validation-separation contract); and the worker LLM (external Claude Code for the developer case, where SDD embeds none; embedded agent-sdk-go only for the non-technical hosted webapp). Keeping the validator and rule-discovery LLM calls next to the graph in one Go process is a further argument for Go over a TypeScript-to-Go bridge. Two contingencies the original Mastra direction carried are resolved rather than dropped: its LangGraph (Python) fallback for "if Mastra proves insufficient" is now moot, since choosing Go means there is no TypeScript/Mastra stack and no held cross-language fallback; and its rejection of the OpenAI and Claude Agent SDKs on vendor-lock-in grounds — tied to the agent-agnostic strategy (d-stg-6za) — is satisfied rather than reopened, because agent-sdk-go is Go-native and multi-provider. Consequence: the CLI-parity MCP server (d-tac-0v4) is downgraded from prerequisite to optional, since in-process needs no bridge and it earns its keep only for non-Go external agents. Supersedes the prior Go-verdict capture (d-cpt-n52), which stated the same recommendation but dropped the LangGraph-fallback and vendor-lock-in threads.

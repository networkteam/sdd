Commits the sdd CLI's styled (TTY) output to a single color scheme keyed to concept, so every command's human-facing rendering reads consistently. Each concept maps to one color; prominence is carried by weight — white-bold, then white, then body grey, then faint — rather than by adding more hues.

Palette (ANSI-256, anchored on glamour's dark style so the styled chrome and the glamour-rendered markdown body read as one piece — body text 252, faint 240):

| Concept | Color |
|---|---|
| Entry ids, anywhere outside the body | gold (220) |
| Kind and live-status words (envelope and tree qualifier) | white bold (15) |
| Other identity values (type, layer) | white (15) |
| Ref kinds (frontmatter ref value and tree verb) | purple (141) |
| YAML keys | cyan (6) |
| Secondary text — summaries, the `↳` why sub-line, other envelope values | body grey (252) |
| Section headings | white bold (15) |
| Structural punctuation, indent guides, `+N truncated` | faint (240) |
| Closed or superseded nodes (whole line, no accents) | receded grey (245) |

Principles: one color encodes one concept; ids always render in the same non-blue color so an id is recognizable at a glance; color lives only on the styled TTY path — lipgloss styles render through a colorprofile writer that downsamples to the terminal and strips color entirely for a non-TTY writer or NO_COLOR, while the plain agent renderer carries none; inactive entries (closed or superseded) recede wholesale so live entries draw the eye.

This concretizes the lipgloss-styled human rendering committed by the three-renderer split (d-cpt-5f4), rests on the output policy's TTY-detected, NO_COLOR-honoring decoration (d-cpt-rkj) and the dual-audience terminal architecture (d-cpt-mvb), and codifies the palette worked out and validated in the sdd show restructure (d-tac-z3k). Existing styled surfaces predate this standard — sdd stats ships its own header, dim, and column-head palette — and should be brought into line as they are next touched. The directive may harden into a guiding contract once the broader terminal-experience work lands.

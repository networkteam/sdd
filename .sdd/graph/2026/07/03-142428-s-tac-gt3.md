Engine startup in Claude Code pays a schema ceremony before the loop can begin: MCP tool schemas arrive deferred, so the agent must spend ToolSearch calls loading the sdd tools before its first `list_sessions`. The deferred loading is Claude Code harness behavior, not shell behavior, so per the agent-agnostic layering the fix belongs in the cheap agent-specific layer — the engine bootstrap skill preloading the schemas in one targeted call, or harness configuration that eagerly loads the sdd server's tools — and not in the MCP surface itself. Two such calls preceded the loop on the first dogfooding run of the v1 workflow engine plan (20260702-220449-d-tac-ry0).

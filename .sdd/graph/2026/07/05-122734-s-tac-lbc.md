The shipped grounding handoff couples evidence transfer to a single global field set: seedFromParent copies only fields named widenReport and anchor, so grounding travels only when the parent names its evidence exactly widenReport — evaluate's `evaluation` field does not travel even today, and slice B parents (groom's scan, catch-up's lanes, interview's dialogue record) would either misname their fields or silently lose the handoff and re-pay the widen the seeding contract was decided to kill. The set is process-global rather than junction-scoped — extending it changes every dispatch pair at once — and the failure mode is silent: a mismatched name transfers nothing, with no load error and no serve note. Resolution decided in review dialogue: restore the per-junction declaration from the seeding directive (20260704-235517-d-tac-tlo) — the dispatching option carries a `seed` mapping written entirely in the parent's spec (child field ← parent field), the shipped {widenReport, anchor} set remains as the no-declaration default, a declared source field missing from the parent fails at load, and a default handoff that finds nothing to carry notes it on the serve. Must land before the slice B specs are authored.

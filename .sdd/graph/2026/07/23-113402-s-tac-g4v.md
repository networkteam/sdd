All four findings of the base-fact index inner evaluation (20260722-115503-s-tac-a0o) are remediated, and the remediation grew into a graph-loading unification, shipped in commit 898d0e7 on branch worktree-base-fact-index and judged merge-ready by a fresh-eyes adversarial review (attached). The strictness split (20260722-120425-s-tac-u22) closes: validity is now part of enrollment via one shared IsIndexed rule, FilterIndexed and IndexedFacts agree, malformed index blocks load as warnings and are quietly excluded, and the opening serve survives hand-edited entries. The store hardening overshoot (20260722-120557-s-tac-xmj) closes: the engine store normalizes every value to its JSON-persisted form at the write boundary, the reflection clone machinery is deleted (store.go net −77 lines), transact/commit atomicity is preserved and re-verified, the time.Time panic is dissolved, and the normalization exposed and fixed two real downstream defects — refs silently dropped and the preflight severity gate silently passing on key-casing mismatch — plus the capture playback template now rendering store documents by their JSON keys. The TopicPath boundary leak (20260722-120753-s-tac-3ga) closes: the factIndex query returns an application-owned FactIndexRow DTO with a plain string topic. The test gaps (20260722-121023-s-tac-v4u) close: the structural-vs-validated divergence is removed by design rather than documented, retired-fact exclusion and topicRaw round-trip are pinned, and upper layers assert rejection instead of the model's error prose. The long-open read-side CQRS leak (20260507-130356-s-tac-m09) also closes: with graph construction unified behind a GraphFinder that holds the model graph and WIP markers, every surviving read-side query struct is pure intent — View, Show, Search, Lint, Attachment, and Preflight all lost their Graph, WIPMarkers, and GraphDir fields, and ListQuery and StatusQuery no longer exist; only WIPListQuery.GraphDir remains, carried into the residue gap. Beyond the findings, the round shipped the partial-read policy Christopher set in dialogue — reading never dies on bad content: LoadGraph and the snapshot path record LoadIssues, sdd lint counts and renders unreadable entries, and a host-neutral graph-health block in the session opening serve makes degradation visible — plus deterministic search tie-breaks (score, then entry ID) in runVector and rrfFuse, fixing a proven hybrid-fusion flake that exact RRF score ties made observable. All gates are green (vet, full tests, engine race, lint zero issues, external example build, binary smokes). The fresh-agent outer evaluation of the base-fact index remains open and unchanged by this round.

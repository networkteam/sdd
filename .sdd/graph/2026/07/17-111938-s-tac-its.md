Commits `bd07c30`, `79e257a`, and review follow-up `17115d1` replace the mechanical-catch-up wording, make a missing or empty `--layout` fail with a pointer to the help reference, and render the reference from implementation-backed vocabulary for functions, renderers, ranking algorithms, decays, and macros instead of maintaining an independent CLI name list. The live vocabulary is assembled once in `finders.LiveViewVocabulary`; the pure renderer exposes a host-neutral `ReferenceBody` shared by future non-CLI consumers, while `Reference` adds only CLI usage and examples. The full CLI reference covers grammar, primitive metadata, macro expansions, and examples; README and the bundled CLI-reference skill template direct users to it. The implementation preserves the standing human/programmatic output boundary: help and validation errors remain human-facing CLI guidance while successful view output semantics are unchanged.

Slice 1 of the public project-aware application plan shipped in commit 941ec4a, freezing the current MCP contract and proving the per-request identity seam before public types move. The complete tool contract—names, descriptions, annotations, and input/output schemas—is now pinned by a deterministic snapshot hash, while the existing end-to-end capture procedure tests remain the semantic replay baseline.

A real stateful Streamable HTTP test now initializes as one user, changes that same user’s scopes and opaque attributes on later requests, and verifies the fresh identity reaches project-resolution, engine-query, and mutation-authorization probe boundaries. Switching the same MCP session to a different user is rejected with HTTP 403 by the SDK’s session fencing. The production bridge is a private protocol-neutral identity value derived from each tool request’s current TokenInfo; it intentionally remains private until Slice 2 publishes the root contract.

Small deviation recorded for accuracy: project routing and the public runtime do not exist yet, so Slice 1 exercises three spike tools through the exact transport bridge rather than production project/query/mutation operations. Later slices wire the already-proven bridge into those real paths. This partially realizes 20260712-234500-d-tac-x1m; Slice 2 remains next.

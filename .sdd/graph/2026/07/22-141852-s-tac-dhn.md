The kind-conditional assemble gate is illegible: when a draft is incomplete it serves every branch's predicate as a flat held list (the drafted kind is not actor / canonical missing / not role / roleActor missing / not focus / involvement missing / refs missing), giving no signal which condition actually applies to the drafted kind. Two concrete harms followed in live runs. On near-root entries the agent fabricated references to satisfy the blanket refs-missing line — the same symptom as a genuine root signal rejected for having no refs; the gate conflates the resolve-or-block invariant (20260628-130400-d-cpt-uh0), which requires refs to resolve, with a requirement that refs exist at all. And on ordinary entries the agent over-provided identity fields (canonical, roleActor, involvement) that do not belong on the kind, leaking them into aspiration, directive, gap, and question frontmatter. Fix direction: serve only the predicates for the drafted kind, and make the refs requirement kind-aware so a genuinely root signal is not forced to invent a reference. Surfaced by the outer evaluation of the bootstrap port (20260722-140955-s-tac-lgc).

Reorientation after context loss must be a first-class engine capability — reachable without a handle, and discoverable through channels that survive compaction. Two commitments follow. First, a connection that has lost its agent-side context must be able to re-serve the live position of the session it is already bound to — framing plus every running move at its current step, each with the report schema needed to continue it — without supplying a session or instance handle, because a compacted agent no longer holds them. This answers the reach gap (s-cpt-h31) that start_session's re-serve and the parked-only resume_session/list_sessions left open. Second, the guidance that tells an agent this capability exists must live in compaction-durable channels — the connection-time server instructions and the tool descriptions the harness re-injects every turn, plus a breadcrumb re-emitted in every serve — never only in one-time session-start prose. This is grounded in how compaction actually works: the durable layer (system prompt, tool and function descriptions, always-loaded instruction files) is reassembled each turn and survives summarization, while transcript prose and one-time tool outputs are flattened — so recovery instructions placed only in served orientation are guaranteed absent exactly when they are needed. The directive builds on the session tier model (d-cpt-h99) by adding a requirement its tier zero never carried: tier zero is no longer only "what an agent needs to not misread a read" but also "how to find your way back after losing your place", and reorientation must now extend to a live-connection session whose context was wiped in place — the case that architecture deliberately excluded from resumability. It generalizes the same durable-channel lesson behind the push-only knowledge reach theme (s-cpt-7wc): guidance an agent must reach under degraded context cannot live only where the engine chose to push it once. It is pending, not guiding: the requirement is concrete and demands the follow-up that realizes it, carried by a separate plan, whose shipping closes this directive.

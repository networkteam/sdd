This retires 20260714-105448-d-tac-kag because every acceptance criterion is implemented, and closes the reproduced startup/migration gap 20260714-103304-s-tac-rcv.

Replacement is same-directory atomic and idempotent; pre-replacement failures clean up newly staged blobs and leave the legacy log untouched.

Non-interactive migration requires the explicit `--migrate-sessions` acknowledgement. The handler migrates sessions independently, logs each failed path, continues the sweep, and returns a non-zero joined error after the normal init lifecycle completes. The runtime therefore also remains healthy if a pre-0.16 server creates another legacy record later.

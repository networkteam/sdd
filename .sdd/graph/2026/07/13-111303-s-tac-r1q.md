Slice 6 of the public project-aware application plan shipped in commit 76ab150, rebasing the MCP engine completely onto the protocol-neutral root runtime and deleting the legacy handler/finder/session implementation. Public `mcpapp` now delegates one tool surface, durable workflow engine, read path, and write gate to `github.com/networkteam/sdd`; `cmd/sdd serve` composes local stores, LLM and embedding adapters, authorized dependencies, and an idempotent Git finalizer, while the nested external module mounts the same HTTP handler behind composition-owned bearer authentication. The slice also replaces the earlier probe-only identity evidence with an end-to-end stateful HTTP workflow test that changes request scopes on one live session, persists filename attachment handles across resume, restores attachment discovery, and exercises full capture on the root path. Repository tests, vet, lint, and the nested-module test pass. This completes Slice 6 of 20260712-234500-d-tac-x1m without closing the seven-slice plan; final merge, publication, and the plan's last release items remain deliberately deferred.

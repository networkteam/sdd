Four implementation decisions refining the session architecture (20260703-232447-d-cpt-h99), settled in dialogue before the build. One: the door tool is `start_session` and the base procedure's canonical is `user-dialogue` — named for what it shells, because autonomous sessions are anticipated as future shells alongside it. Procedures gain an optional frontmatter field `class: shell | move` (default move), extending the procedure frontmatter defined by the type-system contract (20260702-222259-d-cpt-7iy): `start_session` takes a `shell` param defaulting to `user-dialogue`, `start_procedure` refuses shell-class procedures, and the served procedure enumeration lists moves only. Two: landing is nested — when a move ends (completion or abandon) or a session resumes, the response carries the base instance's current serve (handle, standing goal, conclude option, open-threads block) alongside the ended move's own facts, so "never goalless" is told on every response rather than remembered from earlier instructions; the base's long opening text stays cheap through served-instruction memory. The flattened alternative (gluing open-threads and a goal line onto terminal serves) was rejected because it re-creates the reliance on agent memory the architecture exists to remove. Three: session lifecycle reduces to four rules — the door always opens a fresh session showing parked work as continuation options; every other loop tool requires a session and points at the door; leaving a session (disconnect or switching via resume) ends it when nothing is open and parks it when moves are open; listings show parked sessions only, never live-bound ones and never empty shells. Resuming a pre-shell session auto-starts a shell so there is always a base to land on. Four: the framing block shrinks by format, not lanes — measured at 21KB, of which ~15KB is full three-sentence summaries on 22 entries (6 aspirations 4.6KB, 16 guiding directives 10.4KB, focus 3.2KB, participants 2.8KB) — via a brief rendering (first summary sentence only, no attribute brackets) plus heat-ranked caps on aspirations and guiding directives, expected to land near 5-6KB. This takes the framing share of the oversized-serves gap (20260703-224930-s-tac-4hh) into this slice, while compose-serve and injection budgets stay with that gap.

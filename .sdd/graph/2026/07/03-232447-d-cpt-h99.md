Engine sessions open through one door: a session-start tool whose only job is to auto-start a base procedure instance — the session shell as a graph entry — and return its first serve. That serve carries the tier-one knowledge: the compressed SDD process core (the loop, entry types and kinds), how the dialogue should feel (the conduct and register rules compressed from the /sdd skill), the procedure enumeration pulled live from the graph (canonical plus first summary sentence), the session-info header (participant, language, search modes), and routing guidance — check-in via catch-up, free dialogue, or straight into a move, a recommendation, never an auto-run. The base instance never completes on its own: every move nests under it via parent links and lands back on a base junction serve carrying the open-threads block when it ends, so the agent is never goalless before, between, or after moves. The resident step is a pending user junction: free dialogue happens while it pends — reads open, nothing policed, the standing goal "dialogue freely; start a move when something crystallizes" — parking is simply leaving it pending, and its conclude option ends the session gracefully, with open threads surfaced for a per-thread decision before base completes. A closed connection auto-concludes a quiescent session (base as the only running instance — un-logged free dialogue leaves nothing to resume), while open sub-moves park the session for resume; bulk teardown of accumulated parked sessions remains the cheap-teardown gap's territory (20260703-142336-s-tac-j25). Loop tools (start_procedure, next, abandon, resume_session, stage_attachment, list_sessions) reject without a started session, pointing at the door; free reads stay ungated per the guest-surface enforcement principle (20260629-204630-s-cpt-1dz) but carry a one-line breadcrumb to session start while no session runs. Above the serve sit two cheaper layers: connection-time server instructions carry the irreducible tier zero — chosen as what an agent needs to not misread a read: signals and decisions, immutability, summaries are pointers, the door — and per-step units stay tier two, so no path through the tool surface avoids a breadcrumb and the expensive text serves once per consumer. The base entry ships embedded like every base procedure and is project-supersedable — customizing session conduct becomes normal capture. Parked-work discovery leaves the start path, and sessions bound to a live connection are not offered as resumable, distinguishing parked dialogues from ones live in another tab. Two mechanical corrections ride along: session labels apply only after the procedure canonical resolves, and the junction open-threads blocks relocate from bolted-on payload fields to base serves. This resolves the cold-start gap (20260703-224925-s-tac-n55) and the register-carriage gap (20260703-225016-s-cpt-ixa), realizes the interaction-start half of the alignment-junction directive (20260628-154629-d-prc-1ob), gives the locale-rendering item a candidate home (20260703-195207-s-tac-fgy), and names the direction all of this pulls toward: the sdd-engine skill shrinks to a pointer at the door and retires — everything the agent needs arrives served. Third surface-widening refinement of the v1 engine plan (20260702-220449-d-tac-ry0), after session labels and junction payloads.

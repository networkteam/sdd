Slice 2 of the coordinator-lifecycle directive (20260723-114725-d-tac-z6r) — the component layer — is implemented, reviewed, and committed on branch worktree-coordinator-lifecycle (commits 6f3b14f, 2699b1a): typed phase events (connecting, cloning, syncing, indexing) now travel through the reporter mailbox as model.Phase values, footer labels derive from the reported phase rather than bare strings at call sites, and the previously duplicated progress-wiring closures between sdd index and sdd search collapse into one shared embedProgress helper — closing the mislabeled-footer gap on text-only cross-repo search (20260709-152943-s-tac-jbm) by construction. Phase transitions originate in the layer that knows them: EnsureReposFresh emits connecting/cloning/syncing only on real clone or pull work via a command.EnsureReposFreshCmd (matching the callbacks-on-command-structs convention), and the indexing phase is set only when planned chunks exceed zero, so a warm vector search stays completely silent and an indexing plan can never clobber a live syncing phase. The determinate bar renders only in the indexing phase, sdd repo add shows connecting then cloning instead of a bare eternal spinner, and the arming predicate extends to phase-or-real-progress while preserving the zero-work-never-arms invariant from slice 1. The review round (three independent reviews: architecture/layering, AC compliance, bug hunt) additionally surfaced and fixed a real cancellation bug beyond the slice contract: Ctrl-C during a git clone or pull SIGKILLed git and surfaced a raw signal-killed error at exit 1, bypassing the sentinel — the git adapter now prefers the context error and the coordinator treats a cancelled work context as user cancellation regardless of the wrapped error shape. The Phase vocabulary was relocated from internal/command to internal/model with rendering (PhaseLabel) in cliout after the architecture review judged a display vocabulary in the write-intent package the wrong dependency direction. All five slice ACs verified met by independent review with non-vacuous tests; go vet, go test (including -race), and golangci-lint clean.

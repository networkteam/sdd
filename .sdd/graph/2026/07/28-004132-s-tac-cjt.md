An engine session that enters a worktree outside the implementation procedure never receives the branch-binding declaration prompt, and an unbound session is indistinguishable from one correctly bound to the default branch. Observed live: this session entered a worktree from free dialogue at the user-dialogue junction, drove host work directly through subagents, and for the rest of the session read the graph from the base checkout on the default branch. A just-captured entry present on the worktree branch returned `entry not found`, which the agent reported to Christopher as the binding mechanism being broken; declaring the binding made the same read resolve immediately.

Both halves are as designed. The declaration prompt is procedure prose — the fourth acceptance criterion of the branch-binding plan (20260722-112853-d-tac-ln1) places it in the implementation procedure, following that plan's recorded decision to reject automated enter/leave coupling because the agent does the worktree lifting. Its closing done (20260725-203427-s-tac-pev) delivered exactly that, and already concedes a neighbouring coverage hole for older worktree sessions lacking the entry-time prompt. The observation here is the same hole from the other side: worktree entry is reachable from any dialogue path — free dialogue, engage, capture, or an agent doing host work directly — while the prompt lives in one procedure.

The silence is structural rather than a defect in the delivered validation. That validation guards a declared binding that no longer resolves to exactly one checkout; there is nothing to validate when no binding was ever declared, so the session falls through to the configured default branch and every read succeeds against the wrong tree. The resulting symptom — a present entry reported as absent — carries no signal that a branch is involved, which is why it was misdiagnosed as a tool failure. This narrows the launch-context drift family (20260713-121507-s-prc-akz) to the case where nothing drifted because nothing was ever bound.

How to close it is left to a separate dialogue.

Agents skip disciplined moves not because instructions are missing but because a visible shortcut appears sufficient: with an entry summary already in context, grounding or engaging reads as unnecessary work toward the implicit goal, so the agent satisfices — observed repeatedly in real sessions where engage or explore was instructed but not invoked. This re-frames the structural-enforcement finding (s-cpt-h5c): the earlier "instructions don't transfer" reading was the extreme case; the general failure mode is a judgment call that prompt tuning can shift but never remove. The effective counter is economic, extending incentive-over-policing (s-cpt-icg) from report-back gates to move entry: make the disciplined path the cheapest path (an engine that serves pre-fetched chains and data with each goal beats improvising from context summaries); make the implicit goal unreachable without the work's products (writes only through moves whose evidence demands what only the work yields); and shift grounding evidence from self-report into deterministic checks against engine-held session state — a read log of what the agent actually fetched this session, checkable without an LLM judge.

Session labels shipped per the augmenting directive (commit 8e0a71b): `start_procedure` and `next` accept an optional single-line `label` (120-rune cap, validated), recorded as a session-scoped labeled event in the append-only log — the descriptor fold and replay take the last one, so persistence and restart survival came free as designed. With no supplied label the descriptor falls back to the first line of the most recent drafted body and stays blank when nothing was drafted; `list_sessions` and the resume briefing surface the label, and the server instructions teach the label habit plus the pinned vocabulary (a session is one dialogue; instances narrated as threads) once per agent. Tests cover the derivation ladder (blank, body-line fallback, explicit label winning), the single-line and length validation, and restart replay with the label intact; a live stdio run confirmed the descriptor carries the label. One scope note: a label update rides an ordinary loop call — `next` still requires a report, so there is no label-only turn; accepted, since labels sharpen exactly when real turns happen.

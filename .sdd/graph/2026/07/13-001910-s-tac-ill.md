Slice 2 of the public project-aware application plan shipped in commit 6c44c03, publishing the protocol-neutral Go contract without moving the mature MCP behavior. The root package now defines current-request identity and project DTOs, opaque snapshots and canonical document inputs, the consolidated GraphStore, optimistic SessionStore, staged-blob retention, separate embedding and search-index mechanics, raw LLM execution, typed application errors, finalizers, and validated ProjectRuntime construction; it imports no MCP or internal package types.

The new sddtest package ships reusable Run<Port>Tests conformance harnesses for access resolution, graph authority, sessions, staged blobs, embeddings, search indexes, LLM execution, and mutation finalizers. An external-path nested module at examples/extendingsdd compiles fake implementations of every public port against the repository through a development replace, and CI runs that module explicitly because the root module’s ./... pattern does not enter nested modules.

Verification passed for the root and conformance packages with go test and go vet, and the external example passed its own go test. The ambient golangci-lint binary was built with Go 1.24 and cannot analyze the repository’s Go 1.26.1 target; project-toolchain lint is deferred to the final verification rather than treated as a code failure. This partially realizes 20260712-234500-d-tac-x1m; no application behavior moved, and Slice 3 remains next.

`sdd init` registers the SDD MCP server only under project scope; a `--scope user` init installs skills but writes no MCP registration, so an engine session under user scope starts with no server registered and no pre-allowed tools. The deferred half needs the home-dir config surface — `~/.claude.json` (or `~/.claude/settings.json`) for Claude Code and `~/.codex/config.toml` for Codex — plus a merge/ownership policy for shared machine-global config, which differs from the project-scope files committed in the repo. The dbk completion directive (Slice D) explicitly scoped user registration as opt-in; project scope shipped in s-tac-vhh, leaving this as the tracked remainder.

Shipped the fail-fast, fail-loud auto-commit for all sdd commit paths in commit 2a701ef, closing the SIGTTIN hang directive. `gitCommit` now runs `git add`/`git commit` through a `runDetachedGit` helper that detaches the subprocess from any controlling terminal (SysProcAttr Setsid) and bounds it with a 30s context timeout, so an unanswerable SSH/GPG signing prompt can no longer suspend on SIGTTIN. Every commit path (new, summarize, wip start/done, rewrite, lint --fix, init) now returns the commit error instead of printing a stderr warning and continuing — durable but loud: the entry file stays on disk while the failure propagates to the CLI exit / MCP tool result, and `sdd new` reports the created entry before committing so it is still surfaced on failure. Verified by go vet, the full go test suite (including a new fail-loud-and-durable handler test), and golangci-lint clean; plus an end-to-end check confirming the commit succeeds normally when the ssh-agent is reachable and returns an error immediately instead of hanging when it is not. Outer-validated in use by the Codex smoke test (s-tac-yvt). Closes d-tac-zhp.

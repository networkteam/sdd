Offline session-store acknowledgement is triggered by any pending durable session identity transition, whether material remains in the pre-upgrade in-tree layout or a populated global `local/<stable-root-hash>` store must be rekeyed after the repository gains `repo_id`. This refines 20260723-192701-d-tac-g7r from an in-tree-only trigger to one offline mechanism for both transition shapes; permanent aliasing or following the old key after migration remains rejected as standing coexistence surface for a structurally one-time event per repository.

On acknowledgement, migration rekeys the old global store to the repository-ID store with the same aggregate move-if-absent semantics, rewrites `local` session identity in the same offline pass, and updates every tombstone so abandoned locations name the current store. The operation is resumable from a durable manifest across interruption rather than leaving partial targets that block retry.

Declining the prompt, or running non-interactively without explicit acknowledgement, cannot prevent `repo_id` from taking effect in committed configuration because it may arrive through Git. Instead, session-store routing enters a bounded pending state: it continues resolving the current `local/<stable-root-hash>` key, new sessions land there, and a durable marker records the old-key-to-new-key transition. The standing notice keeps the transition visible and `sdd init` prompts again later. This routing hold ends when acknowledged migration completes; it is not a permanent compatibility alias.

Precise session-lock recognition, regular-file-only payloads, store-category path confinement, application-owned versioned identity rewriting, and manifest-driven crash recovery are implementation requirements within the settled migration direction, not additional plan gates. Done evidence must name both acceptance-criterion refinements explicitly: automatic in-tree relocation became acknowledgement on any pending identity transition, and declining now holds session routing on the current key until acknowledged migration completes.

In a fresh Codex engine session, the agent interpreted a user request as permission to resume a semantically matching parked dialogue, did not offer that continuation or ask for confirmation, and thereby failed to follow the served “present as options” and “recommend, never auto-run” instructions.

The trace is direct: `start_session` created and served a new shell; after the user asked to find recent unfinished planned work, the agent announced that it would “pick up the existing check-in” and called `resume_session` with the parked session labeled `Recent planned work not completely finished`. The switch auto-concluded the empty fresh shell and replayed the older catch-up at its existing user junction instead of running a fresh catch-up.

When asked why, the same agent stated that the exact label match led it to infer that the user meant “continue that work,” acknowledged that this inference was wrong, and cited the same served instructions it had failed to follow. The attached observation preserves the user transcript, agent retrospective, persisted timelines for both sessions, relevant instruction text, and the current session-switch behavior, without proposing a solution or asserting another cause.

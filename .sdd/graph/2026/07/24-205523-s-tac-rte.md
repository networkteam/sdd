Commit `4375b3a` completes the store-locality slice of the session branch-binding and store-locality plan (20260722-112853-d-tac-ln1): sessions and staged blobs now live in a machine-global XDG state store keyed by stable repository identity, and linked worktrees share discovery, resume, recovery, and staged-blob access. Identity-less repositories use the Git common directory key; repositories gaining a committed identity use an acknowledged offline local/hash→repo-ID transition that rewrites application-owned local session identity in the same pass. Relocation is aggregate and non-clobbering, with rooted path confinement, strict control codecs, special-file rejection, durable manifests and journals, directory-sync ordering, cooperating-writer locks, collision preservation, and resumable interruption handling. `sdd serve` startup remains unchanged and exposes pending, interrupted, or abandoned state through standing notices.

This slice records two explicitly confirmed refinements to the plan's original relocation criterion. First, automatic in-tree relocation is replaced by an interactive `sdd init` acknowledgement whenever a supported durable identity transition is pending—material in-tree state or a machine-global local/hash store moving to the repo-ID key—with `--migrate-sessions` carrying the same acknowledgement non-interactively; move-if-absent behavior is unchanged once acknowledged. Second, decline or non-interactive execution cannot suppress a committed `repo_id`: instead, routing and newly created sessions remain on the current local/hash key until acknowledgement while a durable pending marker names the desired repo-ID target and the standing notice re-prompts later.

Changing an already established repo identity from A to B remains explicitly deferred as its own graph gap. This slice adds no authority registry, mutation blocking, permanent alias/coexistence protocol, or generalized A→B rekey policy; the exact deferred entry and the two refinements are recorded in the attached implementation evidence.

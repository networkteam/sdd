The engine capture path cannot produce annotation entries. The domain model, the CLI command, and pre-flight fully support the annotation kind (structured topic assignments with optional member subsets, and the merge that makes annotations a first-class clustering mechanism), but the engine's kind-conditional assemble gate has no annotation branch and the engine draft carries no structured annotation-topics field — it collects only plain string topics and generic refs. An annotation drafted through the engine therefore cannot carry its label-to-members assignments and would be structurally invalid at the write gate. This blocks attaching agreed topics to already-captured entries after the fact, which the topic-founding fix depends on. Fix direction: extend the engine write path with an annotation assemble branch and a structured annotation-topics carrier, the same shape already built for actor, role, and focus. Surfaced by the outer evaluation of the bootstrap port (20260722-140955-s-tac-lgc).

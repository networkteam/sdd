All engine graph mutations target an explicit repository-and-branch authority; neither the MCP server's launch directory nor any ambient working directory may select the destination. This addresses the launch-bound placement gap in 20260713-121507-s-prc-akz by rejecting its attached recommendation of one canonical authority per implementation: the established branching design in 20260411-112501-s-cpt-as9 and its real-use validation in 20260608-102050-s-prc-ywh intentionally split coordination on a base branch from implementation evidence on a work branch.

For local implementation, the agent must supply `baseBranch` and `workBranch` explicitly; in-place work makes them equal. Neither is assumed to be `main`. A repository's actual `defaultBranch` is only the default for an ordinary capture whose branch was not explicitly selected. The local adapter resolves an explicit branch to exactly one existing Git-registered checkout and performs graph writes and Git finalization directory-bound there. If none resolves, the mutation fails and procedure state remains: SDD does not create a substitute local checkout, preserving the host-owned worktree boundary in 20260628-130403-d-cpt-h4l.

An authorized connected-repository target instead acquires an ephemeral writable clone from its canonical clone URL, accelerated by and dissociated from read-cache objects. The read cache is never mutated or used as the write origin, and SDD keeps no persistent writable-checkout registry. Remote advancement retries by refreshing, reapplying the immutable mutation, and rerunning target-graph validation before a normal push; protected-branch and PR landing remain deferred and policy rejection never silently retargets.

GraphStore expected revisions protect graph-mutation concurrency only. Commit hashes carried by done signals remain ordinary agent-supplied evidence and do not become checkout cleanliness, code-HEAD, or ancestry gates. This refines the access, GraphStore, and finalizer direction in 20260712-194427-d-tac-wjq with the missing branch-targeted authority distinction. The attached design records the resolver contracts, trade-offs, and rejected alternatives.
